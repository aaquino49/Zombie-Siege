# T-193: Weather sim: rain days and fog nights (data + rules + forecast)

Milestone: M10 | Type: code | Owner: gemini | Scenario: `night_forecast`

GDD §20.1. Every day and night currently plays the same; weather makes the
morning plan react to the sky. This task is the **sim + data + forecast
text** only. Visuals (rain streaks, fog patches, top-bar tag, fogged range
rings) are T-194.

## Scope fence

Touch: new `game/data/weather.json`, `game/scripts/sim/game_data.gd`
(load/validate it), new `game/scripts/sim/weather.gd`,
`game/scripts/sim/game_state.gd` (expose today's weather),
`game/scripts/sim/production_job.gd` (rain farm bonus),
`game/scripts/sim/combat.gd` + `game/scripts/sim/guard_job.gd` (fog range),
`game/scripts/sim/wave_spawner.gd` `forecast()` (add a `fog` flag),
`game/scripts/ui/hud_text.gd` `forecast_text()` and its caller in `hud.gd`,
new `game/tests/test_weather.gd`, the `night_forecast` scenario if needed,
and `project/assumptions.md`. No save-format change. No view/art work.

## Do

1. `game/data/weather.json`:
   ```json
   {"rain": {"first_day": 2, "chance": 0.20, "farm_mult": 1.5},
    "fog":  {"first_night": 5, "chance": 0.15, "range_delta_tiles": -1.0,
             "never_final": true, "no_repeat": true}}
   ```
   GameData loads and validates it like the other data files.
2. `class_name Weather` (static, pure): `day_weather(data, map_seed, day)
   -> "clear" | "rain"` and `night_weather(data, map_seed, night) ->
   "clear" | "fog"`. Each roll uses a **fresh** `RandomNumberGenerator`
   seeded from `hash([map_seed, day, "rain"])` / `hash([map_seed, night,
   "fog"])`. Never touch `GameState.rng`: existing seeded streams, saves,
   bot results and the pacing pin must not shift from RNG consumption.
   Fog rules: night >= first_night; never on the final night (use the same
   final-night check the spawner uses); never if night - 1 was fog (a
   recursive call of the same pure function is fine). Endless nights 21+
   roll normally.
3. `GameState.weather_day() -> String` / `weather_night() -> String` for
   the current day number (thin wrappers over Weather + `map_seed`).
4. Rain: in `production_job.gd` multiply the farm accumulation
   (`food_per_farmer / day_length`) by `rain.farm_mult` when today is a
   rain day. Nothing else changes.
5. Fog: one public helper (e.g. `Weather.range_delta_px(state)` returning
   `range_delta_tiles * Grid.TILE` during a fog **night**, else 0) added to
   the turret range in `combat.gd` and the guard range in `guard_job.gd`
   **after** the watchtower multiplier (tower 7.5 -> 6.5). Clamp the
   result to >= 1 tile.
6. `WaveSpawner.forecast()` result gains `"fog": bool` for that night (it
   needs the seed: add a parameter with a default so existing callers
   compile, and update the HUD caller). `HudText.forecast_text()` appends
   ` · Fog: range −1` on fog nights (format the data delta as an integer
   when whole). The FINAL HORDE line never shows fog.
7. Tests (`game/tests/test_weather.gd`, off-tree per `game/tests/README.md`):
   - same seed/day gives the same result twice;
   - no rain before day 2, no fog before night 5, never fog on night 20,
     never two fog nights in a row (seeds 1..50 x nights 1..40);
   - observed rates over 2000 rolls within ±4 points of the data chance;
   - `GameState.rng` state identical before/after calling the weather functions;
   - farm output on a rain day is 1.5x a clear day (same sim time);
   - turret and tower-guard effective range in fog = data - 1 tile;
   - forecast text has the fog suffix only on fog nights.
8. Run the whole suite. If `test_release_gate_qa` pacing/bot pins move
   **only because of weather effects**, update them to the new measured
   value and record old -> new in `project/assumptions.md`.
9. The `night_forecast` capture shows a fog forecast line (pick a
   seed/day where tonight is fog, or stub the roll in the scenario only).

## Acceptance criteria

- `weather.json` drives every number; GameData validates it.
- Rolls are deterministic per (seed, day), never consume `GameState.rng`,
  and obey the first day/night, no-fog-on-final and no-repeat rules (tested).
- Rain gives farms +50%; fog gives -1 tile for turrets, guards and tower
  guards (tested).
- The forecast line shows "· Fog: range −1" on fog nights only; the
  `night_forecast` capture at 1280x720 shows it.
- All tests pass with no SCRIPT ERROR; import and 300-frame smoke clean.

## Pitfalls

- Range preview code (`build_mode.gd`, `selection_controller.gd`,
  `info_panel.gd`) is **T-194's** job. Don't touch it, but keep the helper
  public so T-194 can call it.
- Don't add weather to the save: it is derived from seed + day.
- Keep LF line endings and explicit static types.
