# T-108: ART: pixel UI kit (OFL pixel font, 9-slice panels/buttons, HUD icons)

Milestone: M6 | Type: asset | Owner: codex | Scenario: `default`

## Goal

Owner request R-5, UI must-have. Make the art for a themed pixel UI so T-109 (one Godot Theme for the HUD) and T-110
(restyled menus) only have to wire it up. The kit comes from the pack's `UI Elements` / `Inventory interface`, plus a
readable OFL pixel font and the transport glyphs the pack lacks. No code or scene changes.

## Context

- Rules: `project/ART_GUIDE.md` (16 px source, ×4 at the node, Nearest, pack palette only, `game/assets/pixel/ui/`).
- `project/art_mapping.md` rows "UI panels" to "floating text" and the section "Survivor looks and UI handoff" say what
  the pack has: `Inventory interface/EMPTY_SLOT.png` (32×22 chamfered frame, 9-slice with 6 px corner margins),
  `USING_SLOT.png` (selected outline), slot icons (gun, ammo, medicine, radio), digits 504–513, colon 514, and battery
  glyphs 517/518. It has **no font, no button states and no pause/play/fast glyphs**.
- Current UI art being replaced: `game/assets/ui/*.png` and `game/assets/icons/*.png` (HUD: food, wood, scrap, ammo,
  pause, play, fast). Screenshot of the current HUD and pause menu: `project/runs/T-090/a1/screenshot_pause_menu.png`.

## Do

1. **9-slice textures** in `game/assets/pixel/ui/`, native size, each with its margins written in `ASSET_INDEX.md`:
   - `panel.png` (large dark panel for HUD bars, roster, info panel, dialogs) and `panel_inset.png` (a darker inner well)
   - `button_{normal,hover,pressed,disabled}.png` and `button_toggle_on.png` (pressed-looking "on" state for the clock
     speed and build-bar buttons). Derive them from EMPTY_SLOT / USING_SLOT with in-palette remaps; pressed insets 1 px.
   - `slider_track.png`, `slider_fill.png`, `slider_grabber.png` (+ `_hover`), `checkbox_{off,on}.png`
   - `bar_background.png`, `bar_fill.png` (HP and progress), `tooltip.png`
2. **HUD icons**, 16×16 unless noted: `icon_food`, `icon_wood`, `icon_scrap`, `icon_ammo`, `icon_survivors`,
   `icon_day`, `icon_night`, and 8×8 transport glyphs `icon_pause`, `icon_play`, `icon_fast` (two triangles),
   `icon_faster` (three). Reuse pack slot icons (ammo from SINGLE_AMMO_SLOT, scrap from tires or debris, wood from logs
   or fences, food from crops) wherever they read at 16 px. Hand-place only the glyphs, with a Pillow script in
   `asset_library/ittaimanero/gapfill/ui_glyphs.py`.
3. **Font**: pick one **OFL** pixel font that is clearly readable at the sizes the UI uses (HUD 16–20 px, titles 32–48
   px). Good candidates are Pixelify Sans, Silkscreen and Tiny5. It must cover A–Z, a–z, 0–9, `: , . ' ! ? - – ( ) / % + ×`.
   Put the TTF/OTF in `game/assets/pixel/ui/font/` with its `OFL.txt`. If you can't download one, hand-build a complete
   glyph atlas with the pack's digits as the style guide, and document how T-109 loads it.
4. Import (`godot --headless --path game --import`). Make sure every PNG uses Nearest and has no mipmaps. For the font,
   set antialiasing off, hinting none and subpixel positioning off in its `.import`.
5. Contact sheet at 4× nearest, `project/runs/T-108/a#/contact_sheet.png`: every texture and state, each 9-slice
   stretched to a button (200×48) and a panel (400×300) size to show the corners hold, all icons, and font samples at 16,
   20, 32 and 48 px rendered with the chosen font, including "Night – dawn in 0:40" and "Wooden Wall 5 wood".
6. `ASSET_INDEX.md` rows (file, purpose, source, 9-slice margins) and a `CREDITS.md` font entry with its licence.

## Acceptance criteria

- Every file listed in Do 1–2 exists with every state, imports cleanly with Nearest, and appears on the contact sheet.
- Stretched 9-slices keep crisp, unbroken corners and borders on the contact sheet.
- The font is OFL (licence file included) or a complete hand-built atlas, and the 16 px sample is readable.
- Only pack palette colours in the PNGs (glyph script checks this). `ASSET_INDEX.md` and `CREDITS.md` updated.
- No `.gd`/`.tscn`/`.tres` changes. Tests, import and smoke pass.

## Pitfalls

- Don't ship the 480×270 `INTERFACE WITH NEW INVENTORY.png` mockup as UI.
- Don't delete the current `game/assets/ui` or `icons` files: the game still uses them until T-109.
- Keep text out of textures (no baked labels).
- Avoid fonts with a CC-BY-NC, "personal use" or unclear licence.
