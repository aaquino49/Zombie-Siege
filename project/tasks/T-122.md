# T-122: Fix: pixel font renders distorted ('v' reads as 'w'); crisp text sizes everywhere (absorbs T-121)

Milestone: M6 | Type: code | Owner: gemini | Scenario: `font_check` (new)

## Goal

Owner request **R-7** (high priority). Since T-109, UI text is hard to read. In
`project/runs/T-109/a2/qa_qa_pixel_theme.png` the lowercase 'v' renders like 'w': "Survivors" reads "Surwiwors",
"David" reads "Dawid", "Victor" reads "Wictor". Other glyphs are uneven too. Make every piece of UI text render
pixel-crisp and readable, and fold in T-121 (the build bar captions are tiny at 11 px).

## Root cause (checked by the quarterback with fontTools)

`game/assets/pixel/ui/font/pixelify_sans.ttf` is drawn on a pixel grid of **11 font pixels per em**: unitsPerEm is
1000 and outline points sit about 90.9 units apart (x: 50, 141, 232, 323, 413, 515, 606, 706...). So one font pixel
covers `size / 11` screen pixels:
- 16 px → 1.45 screen px per font pixel. Some font pixels round to 1 column and some to 2. That turns 'v' into 'w'.
  It's the theme default (`default_font_size = 16`, Label 16, PopupMenu 16, TooltipLabel 14).
- **Crisp sizes are integer multiples of 11: 11, 22, 33, 44, 55, 66.** At 22 every font pixel is exactly 2×2
  screen pixels, which matches the 2× UI pixel scale chosen for T-109.
- The import settings are already right (antialiasing 0, hinting 0, subpixel 0, oversampling 1, no MSDF). Keep them.
  The bug is the sizes, not the importer.
- The variable font's default instance (wght 400) puts a few points up to 10 units off the grid. At 22 px that's
  0.22 px and doesn't change which pixels are filled. Don't change the weight axis.

## Pitfalls

- Don't "fix" the font by turning antialiasing back on: that blurs it, and the owner asked for crisp pixels.
- Don't switch fonts unless 22 px truly can't be made to fit. If you must, use an OFL or CC0 pixel font, put it in
  `game/assets/pixel/ui/font/` with its licence, add it to CREDITS.md, and use the same native-multiple rule for its
  grid. Explain the choice in work.json.
- `Button` font size comes from `Button/font_sizes/font_size`, not Label's. OptionButton popups use PopupMenu's.
- Fixed-size containers (e.g. roster `custom_minimum_size`) clip silently. Look at every capture yourself.
- The phase banner (NIGHT 64 → 66, DAWN/DAY 44) must still fit horizontally.
