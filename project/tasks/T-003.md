# T-003: Grid + seeded map generation (sim)

Milestone: M1 | Type: code | Owner: gemini | Scenario: `default`

## Goal

A pure-logic world model that the view (T-004), placement (T-008) and pathfinding (M2/M3) all share.

## Files to create

- `game/scripts/sim/grid.gd`: `class_name Grid`. `const TILE := 64`. Static funcs: `tile_to_world(t: Vector2i) -> Vector2` (tile center), `world_to_tile(p: Vector2) -> Vector2i` (use floor, so negative coords work), `in_bounds(t: Vector2i, size: int) -> bool`, `rect_tiles(origin: Vector2i, size: Vector2i) -> Array[Vector2i]`.
- `game/scripts/sim/world_map.gd`: `class_name WorldMap extends RefCounted`.
  - `func _init(data: GameData, map_seed: int)` and `generate()`. Uses its own `RandomNumberGenerator` seeded with `map_seed`, never global `randi()`.
  - Per tile: a terrain enum (GRASS, DIRT, ROAD) and an occupant enum (NONE, TREE, SCRAP, ROCK, BUILDING).
  - Resource nodes: `get_node_amount(t) -> int` and `harvest(t, amount) -> int` (returns the amount taken; the tile becomes NONE at 0). Node amounts come from balance.json.
  - `is_passable(t) -> bool`: trees, rocks, scrap piles and buildings are impassable (log the scrap assumption).
  - `command_center_origin() -> Vector2i`: top-left of the 2×2 at the center, (23, 23) on a 48×48 map.
  - Building occupancy storage: `occupy(origin, size, building_id)`, `vacate(origin, size)`, `is_free(origin, size) -> bool`, `building_at(t) -> String`. Placement rules belong to T-008; only the storage lives here.
  - A `changed` signal, emitted when occupancy or nodes change.

## Generation rules (GDD §4; numbers from balance.json, add keys there if T-002 didn't)

- Command Center 2×2 at the center. A clear area of `clear_radius` tiles around it has no trees, rocks or scrap.
- Tree density increases with distance from the center (dense near edges). Scrap piles are more common farther from the center. A few rocks. Some dirt patches and one or two decorative roads crossing near the center.
- Tree/scrap/rock counts land inside the `[min, max]` ranges in balance.json.

## Acceptance criteria

- `game/tests/test_world_map.gd`: same seed gives identical terrain and occupants; different seeds differ.
- The center clear area is empty except the Command Center, which occupies exactly its 4 center tiles.
- Tree/scrap/rock counts are within the balance.json ranges for at least 5 seeds.
- Average tree density in the outer ring (outermost 8 tiles) is higher than in the inner area (tested).
- `harvest` depletes and clears a node; `is_passable` is correct for each occupant type.
- `Grid` conversions round-trip (tested, including negative world coordinates).
- No Node dependencies in sim classes. Tests and the smoke run pass.

## Pitfalls

- Keep generation deterministic: iterate tiles in a fixed order with one RNG.
- `seed` is a global function name in GDScript; don't use it as a parameter name.
- No scene or rendering code here (that's T-004). Keep each file under ~400 lines.
