# T-029: Audio: SFX + ambience + music

Milestone: M5 | Type: asset | Owner: codex | Scenario: `default`
Depends on: nothing open. Asset-only work, so it no longer waits for M4 QA (re-planned 2026-10-10).

## Goal

Put every sound the game needs into `game/assets/sfx/` and `game/assets/music/`, credited and indexed, so T-030
(AudioManager) can wire them to events without searching for files. **No code or scene changes** in this task.

## Sources, in order

1. `asset_library/kenney/kenney_impact-sounds/Audio/` and `asset_library/kenney/kenney_interface-sounds/Audio/`
   (local, CC0, `.ogg`). Use these wherever they fit.
2. CC0 downloads (OpenGameArt or freesound, **CC0 only**, licence checked on the page) for anything Kenney lacks,
   such as a gunshot, zombie groans and music.
3. If you have no network access, or nothing CC0 fits, **synthesise** the sound with a reproducible Python script
   in `project/tools/make_audio.py` (numpy is installed; write 16-bit PCM WAV with the `wave` module). That's
   original work, so credit it as "generated for Zombie Siege, CC0". A layered noise burst with a fast decay makes a
   fine gunshot. Filtered noise with a low pitch wobble makes a groan. Two detuned low sine/saw pads with slow
   amplitude movement make an ambient loop.

## Bookkeeping

- `game/assets/ASSET_INDEX.md`: one row per file (file, purpose, source path or URL, licence, processing).
- `/CREDITS.md`: a "T-029 audio" section naming each source pack/author/URL and the licence (CC0).
- Run `godot --headless --path game --import` so every file gets its `.import`. Commit-ready means the import is
  clean with no errors. Set loop on the two music files' import settings (`edit/loop_mode` for WAV, `loop=true` for
  OGG in the `.import` file), or note in ASSET_INDEX that T-030 must set looping in code.
- If you write a generator script, keep it in `project/tools/` and keep any large intermediate files out of `game/`.

## Acceptance criteria

- Every file in the two tables exists (one extension per name) and imports without errors.
- Every file is CC0 (Kenney, verified CC0 download, or generated) and listed in ASSET_INDEX.md and CREDITS.md.
- Listen-check proxy: report each file's duration and peak level in `work.json` `notes_for_qa` (a small Python
  script is fine). No file is silent or clipped, and the music loops are 30–90 s.
- No changes under `game/scripts/` or `game/scenes/`. Test suite and smoke run still pass.

## Pitfalls

- Don't use anything with an attribution-only (CC-BY), non-commercial or unknown licence.
- Don't commit downloaded zips or raw sources into `game/`. Put raw sources under `asset_library/` if you keep them.
- No scratch files in the repo root.
