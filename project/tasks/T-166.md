## Goal

GDD §18.2. A survivor can be sent off the map in the morning and comes back at dusk with loot, hurt, or not at all.

## Do

1. `game/data/expeditions.json` (loaded and validated by `GameData` like the other files): `morning_fraction 0.4`,
   `max_runs 1`, `max_runs_from_day {"10": 2}`, loot ranges `wood [15,35]`, `scrap [10,25]`, `food [5,20]`,
   `ammo [0,30]`, `loot_per_day 0.02`, `newcomer_chance 0.15`, `hurt_base 0.10`, `hurt_per_day 0.01`,
   `hurt_max 0.30`, `lost_base 0.02`, `lost_per_day 0.005`, `lost_max 0.12`.
2. `game/scripts/sim/expeditions.gd` (`class_name Expeditions extends RefCounted`, weak ref to the state like
   `WaveSpawner`): `can_send(s: Survivor) -> String` ("" or a reason: not morning, guard, already away, run limit,
   sheltered, dead), `send(uid) -> bool`, `active() -> Array`, signals `run_started(s)` and `run_returned(s, result)`.
   - Send: the survivor drops its current job activity and walks to the nearest walkable map-edge tile (Pathfinder).
     On arrival it is **away** (`Survivor.away = true`): skipped by the job, shelter and zombie-target loops, not
     drawn, not counted as a worker. Its job is kept and resumed on return.
   - Return at the DUSK phase change: it reappears on a free tile next to the CC with a result
     `{"loot": {...}, "hurt": bool, "lost": bool, "newcomer": bool}`. Loot goes to `ResourceStore`; hurt halves
     current HP (min 1); a newcomer joins through the normal SurvivorStore path if a bed is free; lost removes the
     survivor (counted in `survivors_lost`, reason "lost on a scavenging run").
   - If it hasn't reached the edge by dusk, the run is cancelled and it walks home with no loot.
   - RNG: **don't draw from `state.rng`** (that would shift every other seeded system). Seed a local
     `RandomNumberGenerator` per run from `hash([state.map_seed, day, s.uid])`, so results are deterministic and need
     no save data.
3. `GameState`: create `expeditions` in `_init`, tick it, and make the job/shelter/zombie code skip away survivors
   (one `is_away()` check in the right places). Keep the edit small.
4. Dawn report: a `scavenging` list (name, loot, hurt/lost) in `last_dawn_report`; T-167 shows it.
5. Tests `test_expeditions.gd`: every can_send reason; a run that reaches the edge is away and returns at dusk with
   loot inside the ranges; the lost/hurt/newcomer branches (force the chances to 1.0 in a test data copy); same
   seed + day + uid → same result; nobody is away at dawn; zombies never target an away survivor.
