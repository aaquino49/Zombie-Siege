## Changes

1. **Build bar keeps its pressed state across the dawn rebuild.** `game/scripts/ui/build_bar.gd`: `_rebuild_buttons()` recreates every button unpressed at dawn, even if BuildMode still has an active type, so the bar and BuildMode disagree.
   - Track the last type passed to `set_active_type()` in `var _active_type: String = ""`.
   - At the end of `_rebuild_buttons()`, call `set_active_type(_active_type)` so the matching button is pressed again. Don't emit `building_selected`.
2. **Typing cleanup.**
   - `game/dev/scenarios/build_bar_day2.gd` and `game/tests/test_build_bar.gd` use untyped `var x = ...` and untyped lambdas (`func(tid): ...`). Use explicit types or `:=` and typed lambda params (`func(tid: String) -> void:`).
   - Type `_bar` as `BuildBar` instead of `CanvasLayer` and call `BuildBar.cost_text(...)` directly.
3. **Clock button contrast.** `game/scenes/ui/hud.tscn`: on the yellow `StyleBoxFlat_pressed`, the white Pause/1x icons and the "2x"/"3x" text are hard to read.
   - On `BtnPause`/`Btn1x`/`Btn2x`/`Btn3x`, add `theme_override_colors/icon_pressed_color`, `icon_hover_pressed_color`, `font_pressed_color` and `font_hover_pressed_color`, all set to `Color(0.2, 0.17, 0.08, 1)`.
4. **No layout shift.** Set `content_margin_left/right/top/bottom` on `StyleBoxFlat_pressed` to match the default Button stylebox margins, so the timer label and speed buttons sit where they did before T-042 (they moved ~4 px).
5. **Line endings.** T-042 converted `game/tests/test_game_clock.gd` and `game/tests/test_placement.gd` to CRLF. Convert both back to LF. **Don't** add a `.gitattributes`: 40+ tracked files (including `board.json` and protected test-runner files) are CRLF or mixed, and a global eol rule would mark them all modified.

Don't change `hud.gd` logic, the ButtonGroup, focus_mode or BuildMode.
