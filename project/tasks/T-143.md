# T-143: Polish: lighter outline on wood/scrap UI icon art so cost icons read without a backing

Milestone: M6 | Type: asset | Owner: codex | Scenario: `victory` | skip_qa

## Goal

After T-132 the build-bar cost icons need a code-drawn cream backing to be visible, because `icon_wood.png` and
`icon_scrap.png` are dark silhouettes on the dark pixel panels. On buttons that are both unaffordable (dimmed) and
behind the Victory modal (Turret, Radio Tower in `project/runs/T-132/a1/victory.png`) the scrap icon is still the
faintest thing on screen. Fix the art itself so the icons read on dark panels with or without the backing.

## Do

1. Files: `game/assets/pixel/ui/icon_wood.png`, `game/assets/pixel/ui/icon_scrap.png` (16x16) and their 2x copies in
   `game/assets/pixel/ui/x2/` (32x32). Find every copy first: `grep -rn "icon_wood\|icon_scrap" game/ --include=*.gd --include=*.tscn --include=*.tres`.
2. Edit the 1x art (palette-exact, binary alpha): add a 1 px light outline (use the ART_GUIDE cream/pale tone, the same
   family as the UI text colour) around the silhouette and/or lift the darkest mid-tones one palette step so the shape
   reads on `#2b2523`-ish panels. Keep the shapes and the 16 px canvas; the outline may use the existing 1 px margin.
3. Regenerate the x2 files by exact 2x nearest-neighbour scaling from the 1x files (same recipe as T-109's
   `asset_library/ittaimanero/gapfill/ui_x2.py`; add the icons to that recipe if they aren't in it). Rerunning the recipe
   must be byte-identical.
4. Before/after sheet in the run folder: both icons at 1x and 4x on the panel colour, the dimmed-button colour and the
   cream backing, plus `victory` and `hud` captures before and after.

## Acceptance criteria

- `icon_wood.png` / `icon_scrap.png` (1x and x2) keep their sizes and names and stay within the ART_GUIDE palette.
- `victory` capture: the scrap icon on the dimmed Turret and Radio Tower buttons is as legible as the wood icon.
- `hud` capture: the top-bar resource icons still look right (the outline must not look heavy at the HUD size).
- No `.gd`, `.tscn` or data file changes. Import, all tests, smoke and screenshot clean.

## Pitfalls

- Do not touch `build_bar.gd` or remove the cream backing (it stays; this is belt and braces).
- Other ready tasks are editing terrain art (T-142) and the font (T-141); stay inside these icon files and the recipe.
- If the `.import` files change only because of reimport, that is fine; don't change import settings (filter stays nearest).
