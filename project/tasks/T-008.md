# T-008: Placement sim: Building instances, BuildingStore, placement rules

Milestone: M1 | Type: code | Owner: gemini | Scenario: `default`
Depends on: T-006 (ResourceStore), T-009 (GameClock for `clock.day`), T-004 (WorldMap, GameState).
**Split:** this task is the sim only. The build bar, ghost preview, mouse input and building sprites are T-040.

## Goal

Buildings become real sim objects: each one has an id, type, footprint and HP, and the map knows which instance sits on each tile. One tested function says whether a building may go at a tile, and `GameState.try_place` pays for it and places it. For M1, placed buildings are complete immediately. M2 (T-012) will turn them into blueprints.

## Files to create / change

1. `game/scripts/sim/building.gd`: `class_name Building extends RefCounted`
   - `var uid: int`, `var type_id: String`, `var origin: Vector2i`, `var size: Vector2i`, `var max_hp: int`, `var hp: int`, `var complete: bool`.
   - `func tiles() -> Array[Vector2i]` (via `Grid.rect_tiles`), `func center_world() -> Vector2` (centre of the footprint in pixels), `func contains(t: Vector2i) -> bool`.
2. `game/scripts/sim/building_store.gd`: `class_name BuildingStore extends RefCounted`
   - `signal building_added(b: Building)`, `signal building_removed(b: Building)`.
   - `func _init(data: GameData, map: WorldMap)`.
   - `func add(type_id: String, origin: Vector2i, complete: bool) -> Building`: creates the instance (size/hp from `data.get_building`), assigns the next `uid` (starting at 1), calls `map.occupy(origin, size, type_id)`, records every tile in `_by_tile: Dictionary` (Vector2i → uid), and emits `building_added`. It does **not** check validity or spend; that's `GameState.try_place`.
   - `func remove(uid: int) -> void`: `map.vacate`, erase the tiles, emit `building_removed`.
   - `func get_at(t: Vector2i) -> Building` (null if none), `func get_by_uid(uid: int) -> Building`, `func all() -> Array[Building]` (in uid order), `func count_of(type_id: String) -> int`.
3. `game/scripts/sim/placement.gd`: `class_name Placement extends RefCounted`, with static functions only.
   - `enum Result { OK, UNKNOWN_TYPE, NOT_PLACEABLE, LOCKED, OUT_OF_BOUNDS, BLOCKED, UNAFFORDABLE }`, checked **in that order**. The first failure wins.
   - `static func check(state: GameState, type_id: String, origin: Vector2i) -> int`:
     - UNKNOWN_TYPE: id not in `data.building_ids()`. Check `building_ids().has(id)` first so `get_building` doesn't `push_error`.
     - NOT_PLACEABLE: `command_center`, or any entry with an `upgrade_from` key (reinforced_wall is an upgrade, handled in a later task).
     - LOCKED: `unlock_day > state.clock.day`.
     - OUT_OF_BOUNDS: any footprint tile outside the map.
     - BLOCKED: `not state.map.is_free(origin, size)` (trees, rocks, scrap and buildings all block).
     - UNAFFORDABLE: `not state.resources.can_afford(cost)`.
   - `static func is_placeable_type(data: GameData, type_id: String) -> bool` (the menu in T-040 uses this).
   - `static func line_tiles(a: Vector2i, b: Vector2i) -> Array[Vector2i]`: a straight line from `a` along the dominant axis (|dx| ≥ |dy| → horizontal), ending at b's coordinate on that axis, inclusive, in order from a. Used for wall dragging.
   - `static func result_text(r: int) -> String`: a short player-facing reason per result, e.g. "OK", "Unknown building", "Can't place", "Locked", "Out of bounds", "Blocked", "Not enough resources".
4. `game/scripts/sim/game_state.gd`
   - `var buildings: BuildingStore`, created after `map.generate()`. Register the Command Center: `buildings.add("command_center", map.command_center_origin(), true)`. It's already occupied by the generator, and calling occupy again is harmless.
   - `func try_place(type_id: String, origin: Vector2i) -> int`: `var r := Placement.check(...)`. If OK, `resources.spend(cost)` then `buildings.add(type_id, origin, true)`. Returns the result. A failed result changes nothing.
5. `game/tests/test_placement.gd` (with `GameState.new(GameData.load_default(), 1337)`, no autoloads):
   - The Command Center is in the store: `get_at` returns the same `Building` for all 4 CC tiles, `count_of("command_center") == 1`.
   - OK: `wooden_wall` at `cc_origin + Vector2i(3, 0)` (inside the guaranteed clear radius).
   - BLOCKED: a shelter overlapping the CC. Any type on a tree tile: find one by scanning `map.occupant_at`, never hard-code coordinates.
   - OUT_OF_BOUNDS: shelter (2×2) at `(size-1, size-1)`; wall at `(-1, 0)`.
   - LOCKED: `radio_tower` on day 1. `storage` is LOCKED on day 1 and OK after `clock.advance(day_length + night_min_length)` (day 2).
   - NOT_PLACEABLE: `command_center`, `reinforced_wall`. UNKNOWN_TYPE: `"castle"`.
   - UNAFFORDABLE: `take` all wood, then a wall.
   - `try_place` success deducts exactly the buildings.json cost (wood 60 → 55 for a wall). Placing again at the same origin → BLOCKED with resources unchanged.
   - Two adjacent walls have different `uid`s. `remove` frees the tiles, after which `check` is OK again and `building_removed` fires.
   - `line_tiles((0,0),(4,1))` → 5 tiles along y=0. `((0,0),(1,-3))` → 4 tiles along x=0 going up. `(a, a)` → `[a]`.

## Acceptance criteria

- Placement validity is fully unit-tested: every `Result` value, plus overlap, bounds, resources, unlock day and line_tiles.
- `try_place` spends exactly the data-driven cost and is all-or-nothing.
- The Command Center is a `Building` in `GameState.buildings`.
- Existing tests, smoke and the `default` screenshot pass unchanged. This task adds no visuals.

## Pitfalls

- `cost` in buildings.json is `{"wood": n, "scrap": n}`. Pass it straight to `ResourceStore.can_afford/spend`.
- JSON numbers load as `float`. Use `int(...)` for size, hp and unlock_day, and `Vector2i(int(s[0]), int(s[1]))` for size.
- Don't read `Game` or `Events` autoloads from `scripts/sim/`. Tests run without them.
- Don't make `Placement.check` spend or mutate anything.
- `WorldMap._buildings` (tile → type id) stays as is. `BuildingStore` is the source of truth for instances.
