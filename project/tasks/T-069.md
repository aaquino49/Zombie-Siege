## Goal

`game/tests/test_ui_layout.gd` (from T-067) calls `bb_panel.force_update_transform()` and
`ip_panel.force_update_transform()` (around lines 36–37) on controls that aren't in the tree. That prints two
non-script `ERROR: Condition "!is_inside_tree()" is true.` lines on every test run. It also has untyped `var`s and
leftover thinking-out-loud comments ("Wait, ...", "Actually ...") in the test and in `_compute_rect`.

## Work

- Delete both `force_update_transform()` calls. The test computes rects from anchors and offsets itself in
  `_compute_rect`, so it doesn't need them.
- Give every `var` an explicit type (`var data: GameData`, `var state: GameState`, `var build_bar: BuildBar`,
  `var bb_panel: Control`, `var screen_size: Vector2`, `var s: Survivor`, `var bb_rect: Rect2`, `var d: float`,
  and so on). ARCHITECTURE.md requires static typing.
- Remove the stray reasoning comments. Keep short comments that explain a non-obvious step.
- Keep every assertion as it is. `test_ui_layout_qa.gd` already covers the exact per-button checks. Don't change game
  code or scenes.

## Acceptance criteria

- The unit-test log has no `ERROR:` lines that come from `test_ui_layout.gd` (search the log around its PASS lines).
- Every var in `test_ui_layout.gd` is statically typed, and the stray reasoning comments are gone.
- All tests pass with no SCRIPT ERROR. Import is clean. Every screenshot is unchanged.
