# T-101: ART: map every game entity to Ittai Manero sprites + gap list + contact sheet

Milestone: M6 | Type: asset | Owner: codex | Scenario: `default`

## Goal

Owner request R-5, step 1. Before anything is swapped, produce a complete, reviewed map from every entity
the game draws to exact Ittai Manero pack sprites, plus an explicit gap list. The quarterback's review of this
task **is the owner-requested approval of the mapping**. No game files change.

## Context

- Read `project/ART_GUIDE.md` first (rewritten by T-100). It defines scale (16 px × 4), view (3/4), animation
  names, anchoring and the trimmed-layer rule.
- Pack: `asset_library/ittaimanero/sprites/` (532 PNGs, named PSD layers `Zombie-Tileset---_NNNN_Capa-NNN.png`,
  trimmed to content, so sizes vary). Overview: `Zombie Apocalypse Tileset Reference.png`. Source:
  `Zombie Apocalypse Tileset.psd` (layer offsets can be read with Python `psd-tools`).
- Current sprites and what they're for: `game/assets/ASSET_INDEX.md`. Entities in data: `game/data/buildings.json`,
  `zombies.json`, `balance.json` (survivor_variants).

## Do

1. Write `project/art_mapping.md` with one table row per drawn entity:
   `entity | current file | pack folder + file(s) | frames × directions | source size / padded cell | notes | GAP?`
   Cover at least:
   - **Terrain:** grass (base + variants), flower/tuft decals, dirt patches, path/road edge pieces (the T-071 autotile
     set: straights, corners, ends, junctions), clearing.
   - **Resource nodes:** trees, rocks, scrap piles.
   - **All 11 buildings + Command Center:** command_center, wooden_wall, gate, reinforced_wall, shelter, farm,
     storage, watchtower, workshop, lumber_yard, turret, radio_tower (check `buildings.json` for the full list),
     plus the blueprint/under-construction look and a damaged look if the pack has one. Say how walls and fences
     join (straight/corner/T pieces).
   - **Survivors:** pack player walk/shoot/knife/damaged frames per direction; how 5+ distinct looks will be made.
   - **Zombies:** walker → Skinny, runner → Kid, brute → Big (Turret zombie spare), unless you find a better fit.
     List walk/attack/damaged/death frames per direction for each.
   - **FX and props:** tracer, muzzle flash (pistol/shotgun), blood, blood stains, corpses with flies, explosion,
     smoke, cars/tires, barrels, signs, bushes, straw, helicopter (rescue).
   - **UI:** what `UI Elements` and `Inventory interface` give (panels, buttons, icons, font?), for T-108.
2. Build a contact sheet `asset_library/ittaimanero/mapping_contact_sheet.png` (copy in your run folder): for
   each entity, the current sprite and the mapped pack sprite(s) at 4× nearest, labelled. For animations, show
   one frame per direction. Keep the script that builds it (`asset_library/ittaimanero/tools/`).
3. End `art_mapping.md` with a **Gap list**: each gap, why the pack has nothing usable, and the planned approach
   (edit/recolor which pack sprite, or new 16 px art). Expected: turret, radio tower, watchtower, guard post,
   survivor variants. Keep it minimal.
4. Also note the frame-alignment approach you verified (PSD offsets or bottom-centre padding) with one example.

## Acceptance criteria

- `project/art_mapping.md` lists every drawn entity with a pack source or GAP, with frame/direction info for
  animated ones and the padded cell size.
- The contact sheet at 4× nearest shows old next to new for every entity.
- The gap list is explicit and minimal (turret, radio tower, watchtower, guard post, survivor variants, anything
  else).
- No changes under `game/` (no copies, no code).

## Pitfalls

- Don't invent folders. Every source path in the table must exist (a reviewer will spot-check).
- Several buildings are modular pieces. Say which pieces compose each building and its footprint size.
- Keep the raw pack out of `game/` in this task. Copying happens in T-102.
