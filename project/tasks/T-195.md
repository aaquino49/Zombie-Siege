# T-195: Idle survivors button + I hotkey

Milestone: M10 | Type: code | Owner: gemini | Scenario: `hud` | skip QA (covered by T-198)

GDD §20.2. Idle survivors quietly waste days; players only notice by
opening the roster. Surface them.

## Scope fence

Touch: `game/scripts/ui/hud.gd` (button), `game/project.godot` (new input
action `select_idle`, key I), the selection/camera hook (use the existing
`SelectionController.select_survivor(uid)`; add a small public
`center_on(world_pos)` to `camera_controller.gd` only if nothing like it
exists), the `hud` scenario, new `game/tests/test_idle_button.gd`,
`project/assumptions.md`. No sim changes.

## Do

1. The top bar shows a compact button **Idle: N** when N > 0 survivors
   have the Idle job during the day. Exclude survivors away scavenging.
   Hidden when N = 0 and at night. Place it where it doesn't overlap the
   resources, day label, speed buttons or the forecast line, and leave
   room near the day label for T-194's rain tag.
2. Clicking it, or pressing **I**, selects the next idle survivor in roster
   order (cycling, wrapping) and centres the camera on them. With none
   idle, I does nothing. I works while BuildMode is active (it just
   selects; it cancels nothing) and is ignored while a menu or the pause
   screen is open.
3. Refresh N from existing job-change / survivor-added / survivor-removed
   signals or the HUD's existing refresh cadence; no extra per-frame scan.
4. Tests: the count excludes guards, workers and scavengers; cycling order
   wraps; hidden at night and at 0; the `select_idle` action exists and
   maps to I.
5. The `hud` capture shows "Idle: 1" (make one survivor idle in the scenario).

## Acceptance criteria

- Button shows the right count by day; hidden at night and at zero.
- Click and I both cycle through idle survivors and centre the camera.
- No overlap with other top-bar items at 1280x720; `UiFont` sizes only.
- All tests pass, no SCRIPT ERROR, import/smoke clean.

## Pitfalls

- Keys in use: WASD/arrows, =/-, Space, 1-3 (speed), F1-F9 (build),
  B (build), R (roster), Esc. I is free.
- The camera is clamped to the map; centring near an edge must not fight
  the clamp.
