- All new code is statically typed.
- All tests pass, and the test output has **no `SCRIPT ERROR` line**. Smoke passes. The `default`, `map_overview` and `camera_zoomed` screenshots look unchanged.
- No stray files in the repo root or `game/` (no `*.log`, `*_out.txt`, `dev_compile.gd`). Write your scratch logs to your run folder, or delete them.

## Pitfalls

- Every T-007 sprite is 64×64 (1×1) or 128×128 (2×2). Scale by footprint anyway.
- `Building.center_world()` is the footprint centre. `Grid.tile_to_world(t)` is the centre of one *tile*. Don't add half a footprint to it.
- Run the unit tests yourself and search the output for `SCRIPT ERROR` before finishing. `TESTS: N passed, 0 failed` alone is not enough.
