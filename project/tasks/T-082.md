# T-082: Cleanup: keep resource nodes off DIRT and type T-075 locals

Milestone: M3 | Type: code | Owner: gemini | Scenario: `map_overview`
Depends on: T-075 (done). Absorbs T-081 (QA's bug report of the same problem).

## Goal

Trees, rocks and scrap must never sit on dirt patches or roads. Also add static types to the locals T-075 added.
This is a small clean-up: no new features, no visual change beyond resources moving off dirt.

## Context

- `game/scripts/sim/world_map.gd` `generate()` (around line 87) builds `potential_tiles`. It skips CC tiles,
  `Terrain.ROAD` tiles and the centre clearing, but **not** `Terrain.DIRT`. So on seed 1337 (`map_overview`
  scenario) trees and rocks show up inside the soft-edged dirt patches.
- Dirt patches (line ~46) and roads (line ~76) are laid **before** this candidate list is built, so `terrain_at(t)`
  is already final when the list is built.
- T-075 added untyped locals in the dirt-stamp loop (lines ~49–54: `var t0 = t`, `t1`, `t2`, `t3`, and
  `for pt in [t0, t1, t2, t3]`) and in `game/tests/test_roads.gd` `test_dirt_patches` (`var tr = ...`,
  `var n/s/e/w = ...`).

## What to do

1. **`world_map.gd` `generate()`:** in the `potential_tiles` loop, also `continue` when
   `terrain_at(t) == Terrain.DIRT`. Change nothing else in generation: same `_rng` calls in the same order up to
   this point. Resource positions will move (the candidate list is shorter), which is expected.
2. **Static typing (ARCHITECTURE.md):**
   - `world_map.gd` dirt-stamp loop: `var t0: Vector2i = t` (same for t1..t3) and `for pt: Vector2i in [t0, t1, t2, t3]:`.
   - `test_roads.gd` `test_dirt_patches`: `var tr: int = map.terrain_at(b)`, and `var n: bool = ...` (same for s/e/w).
     Give the two opposite-grass asserts messages that include the seed and tile, e.g.
     `"DIRT tile opposite grass N+S seed %d tile %s" % [seed_value, t]`.
3. **Regression test** (extend `game/tests/test_roads.gd` or `test_world_map.gd`, whichever already holds the map
   seed tests): `test_resources_off_dirt_and_road`. For seeds 1, 1337, 4242 and 9001: generate, then for every tile
   whose occupant is TREE, ROCK or SCRAP, assert the terrain is GRASS (message with seed, tile and occupant).
   In the same test (or a second one), count each resource type and assert it is at least its `balance.json`
   minimum (`map_trees_min`, `map_scrap_min`, `map_rocks_min`).

## Acceptance criteria

- New test: on seeds 1, 1337, 4242 and 9001, no TREE, ROCK or SCRAP occupant sits on a DIRT or ROAD tile.
- Each resource type still meets its `balance.json` minimum count on those seeds.
- No untyped `var x = ...` locals remain in the T-075 code in `world_map.gd` or `test_dirt_patches`.
- Same seed gives the same map twice (existing determinism test still passes); all tests pass with no SCRIPT ERROR;
  import and smoke are clean.
- `map_overview` screenshot: dirt patches have no trees or rocks on them.

## Pitfalls

- Don't touch the dirt-stamp or road logic itself, the `_rng` order, or `_place_nodes`.
- If an existing test hard-codes a resource position or count that moves because of this change, update only that
  value and say so in `notes_for_qa`. Don't loosen other assertions.
- Use `terrain_at(t)` (it defaults to GRASS), not direct `_terrain[t]` access.
