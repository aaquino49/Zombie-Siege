# T-017: Day/night visuals + night flow

Milestone: M3 | Type: code | Owner: gemini | Scenario: `night`
Depends on: T-009 (clock), T-016 (M2 QA). Uses `GameClock`, `GameState`, `hud.gd`, `world.tscn`, `waves.json` (`final_night`).

## Goal

Make night *look and feel* like night, and give the clock the hook that M3's zombies need: GDD §3 "NIGHT (defense, until wave cleared, min 45 s)". Today the night is a plain 45 s timer with no visual change. After this task:
- the world darkens at dusk and brightens at dawn;
- a "NIGHT n" banner appears at nightfall ("FINAL HORDE" on the final night);
- the top bar shows zombies left at night;
- night ends only when the minimum time has passed **and** the wave is cleared. There are no zombies yet (T-018/T-020), so "cleared" is always true for now and nights still last 45 s.

## Rules

### Tint (world only)
- Day colour `Color(1, 1, 1)`. Night colour `Color(0.42, 0.48, 0.72)` (cool blue). Final-night colour `Color(0.62, 0.34, 0.36)` (red sky, GDD §9) when `clock.day == final_night` (from `waves.json`; later nights go back to the normal night colour, matching `GameData.wave_for_night`'s `is_final`).
- **Dusk:** over the last `DUSK_SECONDS = 12.0` of the day, lerp day → night colour by `1 - time_left / DUSK_SECONDS`.
- **Night:** the night colour, constant.
- **Dawn:** over the first `DAWN_SECONDS = 6.0` of the day (`elapsed < DAWN_SECONDS`, and `day > 1`), lerp the **previous night's** colour → day colour. On day 1 there is no dawn ramp.
- The tint is a pure function of clock state, so it's deterministic, pauses with the game and is testable without a viewport.
- The tint must not darken the UI (HUD, build bar, info panel, roster, banner). `CanvasModulate` only affects its own canvas layer, so put it in `world.tscn` and keep the UI on its `CanvasLayer`s. Verify in the screenshot.

### Banner
- At night, while `clock.elapsed < BANNER_SECONDS = 4.0` (sim time), show a large centred banner "NIGHT n" where n = `clock.day`. On the final night show "FINAL HORDE" instead (red text). At dawn, while `elapsed < BANNER_SECONDS` and `day > 1`, show "DAY n" (smaller, white). Otherwise hidden.
- Fade alpha out over the last 1 s. Again a pure function of clock state.

### Night end + top bar
- `GameClock` gets `var night_end_check: Callable = Callable()`. `_night_can_end()` returns `elapsed >= _night_min_length and (night_end_check.is_null() or bool(night_end_check.call()))`. The clock must still never skip a night or loop forever: keep `advance()`'s existing structure (once the minimum has passed and the check is false, the remaining delta is added to `elapsed`).
- `GameState` gets `func hostiles_remaining() -> int` returning `0` for now, with a comment that T-018/T-020 make it count living zombies plus spawns still queued. `GameState._init` sets `clock.night_end_check = func() -> bool: return hostiles_remaining() == 0`.
- Top bar at night: if `hostiles_remaining() > 0` → "Night – n zombies left"; else → "Night – dawn in m:ss" (the minimum-time countdown, `0:00` once it's passed). By day unchanged ("Nightfall in m:ss"). Put the text in a new `game/scripts/ui/hud_text.gd` (`class_name HudText extends RefCounted`) as `static func night_text(hostiles: int, seconds_left: int) -> String` so it's testable without the HUD scene (`hud.gd` has no `class_name`; don't add one). Refresh the label whenever the text changes (the hostile count can change without the second changing).

## Tests (`game/tests/test_day_night.gd`, new)

- `tint_for`: full day colour at midday; night colour at night; exactly halfway through dusk ≈ the midpoint; day 1 at `elapsed 0` is the day colour (no dawn ramp); day 2 at `elapsed 0` is the night colour and at `DAWN_SECONDS` the day colour; final night uses the red colour.
- `banner_for`: "NIGHT 3" at night elapsed 0.5 on day 3; hidden at elapsed 5; "FINAL HORDE" with `final == true` on `final_night`; "DAY 2" just after dawn; nothing at day 1 elapsed 0; alpha < 1 in the last second.
- `GameClock`: with `night_end_check` returning false, ticking 200 s of night keeps the phase NIGHT and the day unchanged; switching it to true ends the night on the next `advance`. With no check set, behaviour is unchanged (existing clock tests still pass untouched).
- `GameState`: a default state's night still ends after `night_min_length` (hostiles 0).
- `HudText.night_text(0, 44) == "Night – dawn in 0:44"`, `HudText.night_text(7, 0) == "Night – 7 zombies left"`. Use the same dash character in code and tests.

## Pitfalls

- Don't hard-code `20` for the final night: add `func final_night() -> int` to `game/scripts/sim/game_data.gd` (reads `_waves["final_night"]`, default 20, same as `wave_for_night`) with a test, and use it.
- Nodes in unit tests are never in the tree (see `game/tests/README.md`): test the static functions, not `_process` with a viewport.
- `CanvasModulate` placed in `main.tscn` at the root canvas also tints only layer 0, but keep it inside `world.tscn` so world tests own it.
- Don't touch survivor/shelter logic. Night sheltering (T-056) already works.
- Static typing everywhere. Files under ~400 lines. Godot commands only from `project/ARCHITECTURE.md`, always with `--path game`. Scratch output under `project/runs/` or `game/*_out.txt`.
