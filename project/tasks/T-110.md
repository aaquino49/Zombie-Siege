# T-110: Restyle menus + fade transitions (main, pause, Dawn Report, Game Over, Victory)

Milestone: M6 | Type: code | Owner: gemini | Scenario: `main_menu`

## Goal

Owner request R-5 (menus: "restyle + new screens"), first half. The in-game HUD got the pixel theme in T-109 and
crisp font sizes in T-122, but the full-screen menus still look like v1. In `project/runs/T-122/a3/main_menu.png`
the main menu is a pale lavender-grey box with a low-contrast beige tagline, over the old Kenney title art. Give the
five menu screens one consistent pixel look and add short fade transitions. New screens (Settings, How to Play,
Credits) are **T-111**; the live title background is **T-112**. Don't do those here.

## Context

- Theme: `game/assets/pixel/ui/game_theme.tres` (project-wide via `gui/theme/custom`). 9-slice panels and buttons in
  `game/assets/pixel/ui/` (`panel.png`, `panel_inset.png`, `button_*.png`), see `game/assets/pixel/ui/README.md`.
  Font sizes: always a `UiFont` constant (`game/scripts/ui/ui_font.gd`); a test rejects other sizes.
- Scenes / scripts: `game/scenes/ui/main_menu.tscn` + `main_menu.gd`, `pause_menu.tscn` + `pause_menu.gd`,
  `dawn_report.tscn` + `dawn_report_panel.gd`, `game_over.tscn` + `game_over_screen.gd`, `victory.tscn` +
  `victory_screen.gd`.
- Scene flow: `game/scripts/autoload/game.gd` (`Game.start_new_game()`, `restart()`, `quit_to_menu()`, each calls
  `get_tree().reload_current_scene()`).
- Live flow test: `game/dev/scenarios/qa_m4_menu_flow.gd` and `qa_t025_menu_flow.gd`.

## Do

1. **One menu look.** Every screen uses: a dark full-screen dim (`Color(0, 0, 0, 0.55)` or the theme's), a centred
   panel with the theme's 9-slice panel (remove any per-scene `StyleBoxFlat` / `theme_override_styles` that makes the
   lavender box), title in `UiFont.TITLE` (44) with a dark outline or shadow, body text `UiFont.BODY`, buttons from the
   theme at the same width and height across all screens, 22 px button text. Give the title a colour per screen:
   main menu and Victory warm (pack bone/cream), Game Over blood red, pause neutral. Use colours from the pack palette
   (`project/ART_GUIDE.md` §6 Palette).
2. **Main menu:** title "ZOMBIE SIEGE" in `UiFont.BANNER` (66), tagline at BODY in a high-contrast colour, buttons
   stacked vertically (New Game, Quit; leave room for T-111's Settings / How to Play / Credits buttons, e.g. a
   `Buttons` VBox). Until T-112, keep `title_art.png` behind it but darken it (the dim above) so the old Kenney style
   doesn't compete with the pixel panel.
3. **Pause, Dawn Report, Game Over, Victory:** same panel and title style. Stats rows (Game Over / Victory /
   Dawn Report) as a two-column grid, label left, value right-aligned. Keep every existing node path that tests or
   scripts use, or update those references.
4. **Fade:** add `game/scripts/ui/screen_fade.gd` (`class_name ScreenFade extends CanvasLayer`, layer 100, a
   full-screen black `ColorRect` with `mouse_filter = IGNORE` when not fading). API:
   `fade_out(duration := 0.3) -> Signal`, `fade_in(duration := 0.3)`. Make it an autoload or a child of `Game` so it
   survives `reload_current_scene()`. `Game.start_new_game()`, `restart()` and `quit_to_menu()` fade out, reload, then
   fade in. Game Over and Victory panels fade their own panel in (modulate 0 → 1 over 0.3 s).
   The tween uses `set_pause_mode(Tween.TWEEN_PAUSE_PROCESS)` / `process_mode = ALWAYS` so it runs while the tree is
   paused. While fading out, block input (`mouse_filter = STOP`); when done, back to IGNORE.
   **Headless and tests:** if `DisplayServer.get_name() == "headless"` or a `--no-fade` user arg is present, the
   fade is instant (duration 0), so tests, smoke and screenshot scenarios aren't slowed or flaky.
5. **Tests** (`game/tests/test_screen_fade.gd`): fade_out sets the rect to opaque and blocks input, fade_in leaves it
   transparent and `MOUSE_FILTER_IGNORE`; instant mode completes synchronously; the existing menu flow and pause-menu
   tests still pass. Extend `test_ui_font.gd`'s scan if you add scenes.
6. **Captures** (1280×720) into `project/runs/T-110/a#/`: `main_menu`, `pause_menu`, `dawn_report`, `game_over`,
   `qa_m4_victory`, before and after. List them in `notes_for_qa`.

## Acceptance criteria

- `main_menu`, `pause_menu`, `game_over`, `dawn_report` and `qa_m4_victory` captures show the same themed panel,
  title style and button style; no lavender default boxes; all text high-contrast and unclipped.
- The fade plays on New Game, Restart and Quit to Menu, and when Game Over / Victory appear; it works while the tree
  is paused and never leaves input blocked (test).
- Live menu flow (`qa_m4_menu_flow.gd`) still passes. All font sizes are `UiFont` constants.
- All tests pass; import, smoke and screenshot clean.

## Pitfalls

- `reload_current_scene()` frees the current scene: a fade node inside it dies mid-tween. It must live in an
  autoload.
- `await` on a tween in a node that gets freed leaks a coroutine; await the signal from the autoload only.
- Don't leave the fade `ColorRect` at `MOUSE_FILTER_STOP` after a fade-in: every click in the game would be eaten.
- Keep the pause menu's existing behaviour (Esc, volume sliders, hints toggle, blocked hotkeys from T-090).
