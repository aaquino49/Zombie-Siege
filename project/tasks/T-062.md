## 2. HUD day label follows the clock

`game/dev/scenarios/production.gd` sets `state.clock.day = 2` directly to unlock the Workshop, so the top bar still says "Day 1". The HUD only updates `day_label` in `bind()` and `_on_dawn()`.

Fix it in the HUD, not the scenario: in `game/scripts/ui/hud.gd`, keep a typed `var _shown_day: int = -1`. In `_process` (which already refreshes the time label), when `state.clock.day != _shown_day`, set `day_label.text = "Day %d" % day` and store it. `bind()` and `_on_dawn()` should go through the same small helper (`_refresh_day()`), so there's one place that writes the label. Leave `production.gd` as is.

Do **not** emit `clock.dawn` from the scenario: that would run DawnRules (food is eaten and the screenshot changes).

## 3. `SurvivorStore.next_uid()`

`game/scripts/sim/dawn_rules.gd` `_newcomers()` and `game/tests/test_dawn_rules.gd` (`test_name_exhaustion_and_occupied_ring_fallback`) read the private field `state.survivors._uid_counter`. Add to `game/scripts/sim/survivor_store.gd`:

```gdscript
func next_uid() -> int:
	return _uid_counter
```

Use it in both places. Change no behaviour.

## 4. Whitespace

Strip trailing-whitespace-only lines (lines made of just tabs/spaces) in `GameState.tick` in `game/scripts/sim/game_state.gd`. No other edits in that file.
