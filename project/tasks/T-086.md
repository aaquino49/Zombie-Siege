# T-086: GameOverScreen must not show on a won game when bound late

Milestone: M4 | Type: code | Owner: gemini | Scenario: `victory`
Depends on: T-023 (done). Found in the T-023 review.

## Goal

Since T-023, a win sets `state.game_over = true` with `state.won = true` and `state.lose_reason = ""`.
`GameOverScreen.bind()` (`game/scripts/ui/game_over_screen.gd`) shows itself whenever `state.game_over` is true.
So a GameOverScreen bound after a win would show "No survivors remain." on top of the Victory screen. That
happens after T-025's restart rerouting, or in any scenario that wins before `main._ready` binds the screens.

## What to do

1. In `GameOverScreen.bind`, change `if state.game_over:` to `if state.game_over and not state.won:`.
2. Also guard `_on_game_lost` itself: `if _state.won: return` at the top, for safety. This is a one-liner.
3. Add these tests to `game/tests/test_game_over_screen.gd` (keep its existing `before_each`/`after_each` style,
   and only free the screen node):
   - `test_bind_after_win_stays_hidden`:
     - Make a fresh `GameState.new(GameData.load_default(), 1337)`. Set `won = true`, `game_over = true`,
       `lose_reason = ""`.
     - Instantiate a second `game_over.tscn` and bind it to that state.
     - Assert that it isn't visible, that `clock.paused` is still false and `clock.locked` is false (GameOverScreen
       didn't touch them). Free that screen.
   - `test_bind_after_loss_shows_immediately`:
     - Set `game_over = true`, `won = false`, `lose_reason = "command_center"`, then bind a new screen.
     - Assert that it is visible and that the Reason text is the Command Center message.

## Acceptance criteria

- `GameOverScreen.bind` on a state with `won == true` leaves the screen hidden and the clock untouched.
- `GameOverScreen.bind` on a lost state (`game_over` true, `won` false) still shows straight away.
- All tests pass with no SCRIPT ERROR. The `victory` and `game_over` screenshots are unchanged.

## Pitfalls

- GameState and GameData are RefCounted. Never call `.free()` on them.
- Don't touch VictoryScreen or `GameState` in this task.
