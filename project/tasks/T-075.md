# T-075: Polish: soft-edged dirt patches using the path autotiles

Milestone: M3 | Type: code | Owner: gemini | Scenario: `map_overview`
Depends on: T-071 (done). Review follow-up from T-071. Terrain visuals only.

## Problem

`WorldMap.generate()` stamps random DIRT patches (`map_dirt_patches`) as cross/diamond blobs, and
`world_view.gd::_draw_ground` draws them with hard-edged `dirt.png`/`dirt_2.png` squares. Next to T-071's soft,
grass-edged tracks they look blocky and stepped. See the bottom right of `project/runs/T-078/a1/screenshot_qa.png`
and `project/runs/T-071/a1/map_overview_qa.png`.

## Work

1. `game/scripts/sim/world_map.gd` (the patch loop near line 43): every DIRT tile must belong to at least one full 2x2
   block of DIRT/ROAD tiles. The simplest way is to stamp a 2x2 block (`t`, `t+(1,0)`, `t+(0,1)`, `t+(1,1)`) for each
   patch tile instead of a single tile, clamped to the map. Never overwrite ROAD. Keep the `_rng` call sequence the
   same, so each seed's trees, rocks, scrap and roads change as little as possible. If a 2x2 doesn't fit at a map edge,
   skip the whole block rather than leave a 1-wide sliver. Then make sure no DIRT tile has grass on opposite sides
   (N+S or E+W): fill the gap or revert that tile to GRASS.
2. `game/scripts/world/world_view.gd::_draw_ground`: draw DIRT tiles the way ROAD tiles are drawn, using
   `PathTiles.path_tile_for(_state.map, t)`. `PathTiles._is_grass` already treats DIRT as path interior. Where it
   returns `"center"`, keep the existing `dirt.png`/`dirt_2.png` hash variant, so large patches keep their texture.
3. Movement, resources, the CC clearing and the road layout don't change. Resource nodes never land on DIRT/ROAD.

## Acceptance criteria

- New test (in `test_roads.gd` or a new `test_dirt_patches.gd`): for seeds 1, 1337, 4242 and 9001, every DIRT tile is
  inside a 2x2 block of DIRT/ROAD tiles, and no DIRT tile has GRASS on both N and S or on both E and W.
- Extend `test_world_view_qa.gd`: a DIRT cell with a grass neighbour uses the `res://assets/tiles/path/` source that
  matches `PathTiles.path_tile_for`.
- The `map_overview` screenshot shows dirt patches with rounded grass edges, not stepped squares.
- The same seed gives the same map twice (the existing determinism tests pass).
- All existing tests pass with no SCRIPT ERROR; import and smoke are clean.

## Pitfalls

- If an existing world-map test counts exact DIRT tiles or hard-codes a resource position that now moves, change only
  that number and say so in `notes_for_qa`. Don't weaken what the test checks.
- Don't change `map_dirt_patches` in balance.json.
- `_draw_ground` runs once at bind. Don't add per-frame work.
