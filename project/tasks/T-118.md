# T-118: ART: gap-fill sprites in the Ittai Manero style (survivor recolours, turret, radio tower, watchtower, rocks, helicopter)

Milestone: M6 | Type: asset | Owner: codex | Scenario: `default`

## Goal

Owner request R-5, step 2 (part 2 of 2). Draw only the gaps from the approved `project/art_mapping.md` "Gap list", in
the pack palette, at 16 px, in 3/4 view, and put them in `game/assets/pixel/` next to the files T-102 made. No code
changes.

## Context

- Rules: `project/ART_GUIDE.md` §6 (palette only, pack black outline) and §7 (gap-fill process: edit/recombine first,
  then recolour, then hand-placed pixels via a Pillow script, one script per asset in
  `asset_library/ittaimanero/gapfill/`). Image generation may be used only as a reference and never ships.
- T-102 produced the padded base strips (`game/assets/pixel/characters/player_*`) and the processing script
  `asset_library/ittaimanero/tools/process_pack.py`. Use the same cell sizes and naming.
- Palette: `asset_library/ittaimanero/palette.json` (41 colours). Survivor shirt colours proposed in art_mapping
  "Survivor looks and UI handoff".

## Do

1. **Seven survivor variants**, one per `game/data/balance.json` `survivor_variants` id (blue, brown, green, old,
   survivor, hitman, soldier). Recolour the T-102 player strips with semantic masks: shirt cloth always; hair and/or skin
   where it helps tell them apart (old = grey hair). Keep eyes, highlights and outlines. Output
   `characters/survivor_<id>_walk_{down,left,up,right}.png` and `survivor_<id>_hurt_{dir}.png` with the same 16×16 cell
   layout as the player strips. Leave hurt frames' red/black/white silhouettes authored (don't tint them by shirt).
2. **Turret** (1×1): `buildings/turret_base.png` 16×16 plus `turret_barrel_{down,left,up,right}.png` (4 facings, same
   cell, shared pivot). Built from pistol 335 / shotgun 332 and Road detail 55 per the mapping.
3. **Radio tower** (2×2): `buildings/radio_tower.png`, 32×48 cell, 32×32 footprint at the bottom.
4. **Watchtower** (1×1): `buildings/watchtower.png`, 16×32 cell, 16×16 footprint at the bottom, raised wooden deck
   from fence pieces.
5. **Rocks**: `props/rock_a.png`, `props/rock_b.png`, 16×16, grey angular boulders with the pack outline.
6. **Rescue helicopter**: `fx/helicopter_body_left.png` and `_right.png` (mirror), 48×32, plus
   `fx/helicopter_rotor.png` as a 3-frame strip of 48×48 cells. Body hub at (24,16), rotor hub at (24,24) in source px.
   The fly-in comes from the upper right (`rescue_helicopter.gd` START_OFFSET), so `left` is the one that shows.
7. **Not in scope:** guard post (no task draws guard positions yet; dropped from M6), UI transport glyphs and the font
   (T-108 owns them).
8. Import (`godot --headless --path game --import`), add `ASSET_INDEX.md` rows (purpose, pack sources, "gap-fill:
   edited/recoloured/hand-placed"), and make a 4× contact sheet `project/runs/T-118/a#/contact_sheet.png`: every gap
   sprite next to the pack sprites it will sit beside in-game (survivors next to a walker and the player; turret,
   watchtower and radio tower next to the T-102 command_center and fence pieces; rocks next to trees). Add a walk GIF
   for all seven survivors side by side.

## Acceptance criteria

- Every gap family above has its files in `game/assets/pixel/` at the stated cell sizes, importing cleanly with Nearest.
- Only `palette.json` colours appear (the script checks and prints this); black pack outline; 3/4 view.
- The seven survivors are clearly distinct from each other and from the walker/runner/brute on the contact sheet,
  and their walk GIF shows no jitter.
- One re-runnable script per asset family in `asset_library/ittaimanero/gapfill/`.
- `ASSET_INDEX.md` updated. No `.gd`/`.tscn` changes. Tests, import and smoke pass.
