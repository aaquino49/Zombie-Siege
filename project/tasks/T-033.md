# T-033: Windows export build

Milestone: M5 | Type: code | Owner: gemini | Scenario: `default`

## Goal

Produce a working Windows build of v1: `builds/ZombieSiege.exe`.

## Context

- Godot 4.7.2 export templates are installed. The project is in `game/`. `builds/` is already in `.gitignore`.
- App icon: `game/assets/icon/icon.png` (project setting `application/config/icon`) and
  `game/assets/icon/icon.ico` for the exe.
- Renderer: GL Compatibility. Keep the project's default texture filter as it is.
- Runs after T-098 (pacing data) and T-032 (tutorial hints), so the build contains the final v1 content.

## Do

1. Create `game/export_presets.cfg` with one preset named exactly `Windows Desktop`:
   - platform Windows Desktop, `export_path="../builds/ZombieSiege.exe"`, PCK embedded (single exe), x86_64,
     `application/icon="res://assets/icon/icon.ico"`, product name "Zombie Siege", file/product version
     `1.0.0.0`, company name "Zombie Siege AI Team".
   - Exclude tests: `exclude_filter="tests/*"`. Keep `dev/` unless you confirm nothing at runtime loads
     `res://dev/` (DevTools loads `res://dev/scenarios/*.gd` for `--scenario=`; T-034 needs that to work in the exe
     only if it's cheap, so keeping `dev/` is the safe default).
   - Code signing off. Icon embedding needs rcedit; if rcedit isn't configured, keep the icon setting, accept the
     export warning, and note it in `work.json`.
2. Set `application/config/version="1.0.0"` in `game/project.godot`.
3. Export: `godot --headless --path game --export-release "Windows Desktop" ../builds/ZombieSiege.exe`.
4. Smoke the exe: `builds/ZombieSiege.exe --headless -- --quit-frames=120` must exit 0 with no `ERROR:` or
   `SCRIPT ERROR` lines. Also run it once without `--headless` (still with `-- --quit-frames=120`) to confirm a
   window opens and closes.
5. Add an "Export Windows build" row to the Commands table in `project/ARCHITECTURE.md`.

## Acceptance criteria

- `game/export_presets.cfg` exists with the `Windows Desktop` preset; the export command exits 0.
- `builds/ZombieSiege.exe` exists (single file, PCK embedded) and the headless 120-frame smoke exits 0 with no
  ERROR lines. Exe size and smoke output are in `work.json`.
- Export command documented in `project/ARCHITECTURE.md`.
- `builds/` stays ignored (no binaries in the diff). All tests, import and smoke still pass.

## Pitfalls

- Never launch the exe without `--quit-frames`; it never returns.
- Don't change game code or data. If the export fails because of a code problem, report blocked with the exact
  error.
- `export_presets.cfg` must be committed (no signing credentials in it).
