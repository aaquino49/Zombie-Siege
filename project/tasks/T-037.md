# T-037: World view + camera cleanup (static typing, constants, viewport fallbacks)

Milestone: M1 | Type: code | Owner: gemini | Scenario: `map_overview`
Depends on: T-004, T-005 (both done). **T-039 has been merged into this task.** Runs before T-040, which rewrites building drawing in `world_view.gd`.

## Goal

Bring the T-004/T-005 world and camera code up to ARCHITECTURE.md (static typing, no magic numbers, no duplicated math) before build mode adds more code to the same files. **No visible or behavioural change.**

## Files to change

1. `game/scripts/world/camera_controller.gd`
   - Add `class_name CameraController` (keep `extends Camera2D`).
   - Remove `const CameraMath = preload(...)`. `CameraMath` already has a `class_name`; use it directly.
2. `game/scripts/world/camera_math.gd`
   - Add `const ZOOM_MIN := 0.5` and `const ZOOM_MAX := 2.0`; `clamp_zoom` uses them.
   - Add `static func viewport_size_for(node: Node) -> Vector2`: if `node.is_inside_tree()`, return `node.get_viewport().get_visible_rect().size`. Otherwise return `Vector2(ProjectSettings.get_setting("display/window/size/viewport_width"), ProjectSettings.get_setting("display/window/size/viewport_height"))`.
3. `game/scripts/world/world_view.gd`
   - `@onready var camera: CameraController = $Camera2D` so `camera.map_px` is type-checked.
   - Type every local and parameter: `var tileset: TileSet`, `var tex: Texture2D`, `var source: TileSetAtlasSource`, `var size: int`, `var t: Vector2i`, `var terrain: int`, `var source_id: int`, `var hash_val: int`, `var occ: int`, `var path: String`, `var sprite: Sprite2D`, `var max_dim: int = maxi(...)` (use `maxi`, not `max`), `var to_remove: Array[Vector2i] = []`.
   - Named constants replace the magic tileset source ids: `const SRC_GRASS_FIRST := 0`, `const GRASS_VARIANTS := 3`, `const SRC_DIRT_FIRST := 3`, `const DIRT_VARIANTS := 2`, `const SRC_ROAD := 5`. Use `Grid.TILE` instead of the literal 64 and `Vector2(Grid.TILE, Grid.TILE)` instead of `Vector2(32, 32) * 2`-style literals where they mean tile size.
   - Extract the Command Center centre maths (currently duplicated in `bind()` and `_draw_buildings()`) into one `func _cc_center() -> Vector2`. It returns `Grid.tile_to_world(origin) + Vector2(Grid.TILE, Grid.TILE) / 2.0`.
   - `bind()`: replace the `Vector2(1280, 720)` fallback with `CameraMath.viewport_size_for(camera)`, and call `CameraMath.clamp_position(...)` directly instead of `camera.CameraMath`.
4. `game/dev/scenarios/camera_zoomed.gd`
   - Type the locals: `var world: Node2D`, `var cam: CameraController`, `var size: int`. Rename the parameter to `main: Node` if it isn't already typed.
   - Remove the local `preload` of camera_math and the hard-coded `Vector2(48, 48) * 64` and `Vector2(1280, 720)`. Use `Game.state.map.size()` and `CameraMath.viewport_size_for(cam)`.
5. `game/dev/scenarios/map_overview.gd`: type the locals (`var world: Node2D`, `var camera: Camera2D`, `var size: int`). Use the `Game` autoload directly (`Game.state`) instead of `tree.root.get_node("Game")`, and `Grid.TILE` instead of `64.0`.
6. `game/scripts/sim/game_state.gd`: rename the unused `tick` parameter to `_delta` (silences UNUSED_PARAMETER). T-009 will use it again.

## Acceptance criteria

- No untyped `var` declarations remain in `world_view.gd`, `camera_controller.gd`, `camera_zoomed.gd` or `map_overview.gd`. Every var has `: Type`, or uses `:=` with an obvious type.
- The Command Center centre is computed in exactly one helper (`_cc_center`) in `world_view.gd`.
- No `1280`/`720` literals in `world_view.gd` or `camera_zoomed.gd`. `CameraMath` is referenced only via its `class_name` (no `preload` of camera_math.gd anywhere). `ZOOM_MIN`/`ZOOM_MAX` exist and are used.
- All existing tests (`test_world_view_qa.gd`, `test_camera_math.gd`, `test_camera_controls_qa.gd`, `test_game_state.gd`, ...) pass unchanged. Smoke passes.
- `map_overview` and `camera_zoomed` screenshots look identical to the T-004/T-005 ones (camera_zoomed is the 2x view clamped at the top-left corner).

## Pitfalls

- Adding `class_name CameraController` means no other script may declare that name. Grep first.
- `get_viewport_rect()` exists only on CanvasItem. The helper takes a `Node` and uses `get_viewport().get_visible_rect()`.
- ProjectSettings returns a Variant. Wrap it in `float(...)` when building the Vector2.
- `game/tests/test_camera_math.gd` line 3 also has `const CameraMath = preload(...)`. Delete just that line (the class_name resolves the same). Change nothing else in the tests, and say so in `work.json`.
- Pure refactor. Don't change generation, the tileset choices or camera behaviour.
