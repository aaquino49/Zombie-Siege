# T-214: ART: tech upgrade icons (one per GDD §23 upgrade)

Milestone: M12 | Type: asset | Owner: codex | Scenario: `default`

Depends on: T-213 (approved design), T-224 (M12 art batch 1: match its icon
style). Asset-only; may run beside any code task.

## Problem

The tech-tree screen (GDD §23.5, T-218) shows one 16×16 icon per upgrade
card. T-224 already made the Field Lab, Campfire, mood, research and
branch icons; this task makes the nine upgrade icons from the GDD §23.3
table.

## Scope fence

Create new files only:

- `game/assets/pixel/ui/tech/<id>.png`, 16×16 native, for each id:
  `spotters`, `oiled_turrets`, `reinforced_frames`, `better_tools`,
  `crop_rotation`, `ammo_press`, `camp_songs`, `first_aid`, `bunk_beds`
- `game/assets/pixel/ui/x2/tech/<id>.png`: exact 2× nearest copies, made
  the same way as the existing `game/assets/pixel/ui/x2/` icons
- the matching `.png.import` files (run the project import)
- `CREDITS.md`, `game/assets/pixel/ui/README.md` and
  `game/assets/ASSET_INDEX.md` rows for these nine icons only
- a contact sheet and a short README under `project/runs/T-214/`

No `.gd`, `.tscn`, `.tres` or `game/data/*.json` changes; do not edit or
overwrite any existing PNG.

## Do

1. Read `project/ART_GUIDE.md`, `game/assets/pixel/ui/README.md` and
   T-224's icons (`icon_research.png`, `icon_tech_*.png`,
   `icon_mood_*.png`) and match their outline weight and palette.
2. One icon per upgrade, pack parts first. Suggested motifs (pick
   whatever reads best at 1x):
   - `spotters`: binoculars or an eye over a crosshair
   - `oiled_turrets`: an oil can, or a turret barrel with speed lines
   - `reinforced_frames`: a wall plank with metal braces or bolts
   - `better_tools`: an axe crossed with a wrench
   - `crop_rotation`: a wheat sheaf with a circular arrow
   - `ammo_press`: a stack of bullets on a press or a crate of shells
   - `camp_songs`: a flame with a music note
   - `first_aid`: a med kit or a red cross
   - `bunk_beds`: a two-level bed
3. The three icons of one branch should share a dominant hue that
   matches that branch icon (T-224), so a column reads as one branch.
4. Contact sheet: every icon at 1x, 2x on `panel.png`, in greyscale,
   and laid out as the 3×3 tech screen (columns Defense, Economy,
   Survivors, tier 1 at the top) next to the three branch icons.
5. Run the import so every new PNG has its `.png.import`.

## Acceptance criteria

- All 9 + 9 files exist at 16×16 and 32×32, binary alpha, pack palette
  only, and the x2 copies are exact 2× nearest of the native files.
- The nine icons are distinct from each other and from the existing HUD
  icons at 1x on the panel and in greyscale (contact sheet shows it).
- `CREDITS.md`, the UI README and ASSET_INDEX list them; no raw pack
  files copied.
- Project imports; full suite and 300-frame smoke clean (no code
  changed).

## Pitfalls

- Pack first, generated art last; recolour any generated art to the
  pack palette exactly.
- Icons sit on the 11 px font grid (UiFont) and keep 1 px outlines so
  they stay crisp at the UI's 2x.
- File names are exactly the upgrade ids above (T-218 derives the path
  from the id).
- Keep LF line endings in the README and CREDITS edits.
