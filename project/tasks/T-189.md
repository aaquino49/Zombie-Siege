Milestone: M9 | Type: design | Owner: claude | Scenario: `default`

T-186 adds nights 21+ on the base wave formula and T-188 makes defence
ranges visible (placement quality goes up). Check the economy and pressure
still hold with the balance bot before T-190 certifies M9.

## Scope fence

Data-only (`game/data/waves.json`, `game/data/balance.json`,
`game/data/zombies.json`) plus the iteration log
`project/runs/T-189/iterations.md`. File a code task if a script change is
needed; do not edit scripts here. Update test pins only where numbers
moved (no behaviour-change edits).

## Do

1. Run bot v3.1 `sensible` and `scavenger` on seeds 1337,1–9, Normal and
   Hard, 25 nights (endless to night 25): record wins by 20, survival to
   25, CC damage nights, dusk ammo/scrap.
2. Targets: Normal sensible still ≥ 8 won by night 20 with 0 losses before
   night 15 (T-169 baseline); a held base reaches night 23+ on most Normal
   seeds without hitting the 300 s cap every night; Hard 4–7 won with CC
   damage on several seeds; `none` still loses around night 3.
3. Tune only if a target misses, preferring post-20 wave growth (counts or
   sides) over touching nights 1–20. Keep the seed-1337 1x full-run time
   under ~46 min.
4. Write the final table + changed values and why into
   `project/decisions.md` (T-169 pattern).

## Acceptance criteria

- Iteration log with ≥ 3 runs and the final 10-seed table in decisions.md.
- All four targets met or the miss explained as a bot limit (T-027 precedent).
- Full test suite passes; import/smoke clean.

## Pitfalls

- Do not retune nights 1–20 to fix endless; endless is bonus time, the
  balanced game is nights 1–20.
- Walker HP has a hits-to-kill cliff (T-147); prefer counts over HP.
