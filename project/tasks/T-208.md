# T-208: Reload day from the dawn autosave (pause menu)

Milestone: M11 | Type: code | Owner: gemini | Scenario: `default`

GDD §21.2. UI + load-flow only; no sim, data, bot or Continue-flow changes.

## Problem

Continue loads `user://savegame.json` from the main menu, but a player who
ruins a day has no way to undo it without quitting to the menu. The pause
menu should expose the same dawn snapshot as **Reload day**.

## Scope fence

Touch: `game/scripts/ui/pause_menu.gd` (one button + show/hide logic),
`game/scripts/autoload/game.gd` (reuse the existing SaveGame load plus
scene-reload flow), `game/tests/test_pause_menu.gd` or one new reload test
file, one How to Play line, and `project/assumptions.md` if needed.
Do NOT touch: any sim file, `game/data/*.json`, `balance_bot.gd`,
`dev/balance_run.gd`, or the Continue flow itself.

## Do

1. Add a **Reload day** button to the pause menu. Show it only when a valid
   dawn autosave exists (hide before the first dawn, and on broken or
   old-version saves without crashing).
2. Reload loads `user://savegame.json` exactly like Continue: same seed,
   day, resources, buildings, survivors, difficulty, endless flag handling
   unchanged, clock at full daylight, via the existing SaveGame load plus
   scene-reload flow (no duplicated parsing).
3. Add one How to Play line documenting Reload day.
4. Tests: reload restores dawn resources/day/seed/difficulty; no-save case
   hides the button; broken-save case hides it without errors.
5. Run the full suite, import and 300-frame smoke; default screenshot
   unchanged apart from the menu button.

## Acceptance criteria

- Pause menu shows Reload day when a valid dawn save exists and hides it
  otherwise (e.g. before the first dawn).
- Reload restores the dawn snapshot exactly like Continue (day, seed,
  resources, difficulty, clock at full daylight).
- Broken or old-version save hides the button without crashing; full suite,
  import and smoke clean; default screenshot unchanged apart from the menu
  button.

## Pitfalls

- Reuse the Continue load path; do not fork save parsing.
- Never touch endless flags or records beyond what Continue already does.
- Keep LF line endings and explicit static types.
