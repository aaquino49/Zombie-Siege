## Acceptance criteria

- Before/after contact sheet for every area above in `project/runs/T-113/`.
- All tests pass, smoke clean; 10-seed balance outcomes match the T-136 decision entry.
- Night and Final Horde captures show readable zombies and a red night 20.
- `bugs.json` written (empty array if none); each bug has a title, severity and the capture that shows it.
- Severity rule for `bugs.json` (owner request R-10: ship v1.1 now): **blocker** = crash, data loss, or something a
  player would call broken in the first 10 minutes (missing/garbled sprites, unreadable UI, a menu that doesn't work);
  **major** = visibly wrong but the game plays; **minor** = polish. Only blockers hold up the v1.1.0 export (T-114).

## Pitfalls

- Never `git commit/reset/checkout/stash`; use `git archive` into a temp dir or the existing v1 PNGs for "before".
- Don't fix bugs in this task; file them.
- Keep scratch output out of the repo root (use `project/runs/T-113/`).
