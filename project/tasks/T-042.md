# T-042: Polish: clock speed buttons' pressed state + static typing cleanups (absorbs T-043)

Milestone: M1 | Type: code | Owner: gemini | Scenario: `clock`
Depends on: T-009, T-008. Small follow-ups from the T-009 and T-008 reviews, merged into one task. No behaviour changes.

## Goal

The active clock speed is obvious at a glance, and the last untyped `var`s in the clock and placement code get static types (ARCHITECTURE rule 3).

## Changes

1. **`game/scenes/ui/hud.tscn`: pressed state.** BtnPause/Btn1x/Btn2x/Btn3x are toggle buttons in a ButtonGroup. Their pressed state is only a slightly darker background, which is hard to read on the grey top bar. Add one shared `StyleBoxFlat` sub-resource and use it as the `theme_override_styles/pressed` (and `hover_pressed`) of all four buttons, e.g. a light fill `Color(0.95, 0.85, 0.45)` with a 2 px darker border and 4 px corner radius. The icon/text must stay readable on it. Don't change the ButtonGroup, `focus_mode` or any `hud.gd` logic.
2. **`game/tests/test_game_clock.gd`:** type every local, e.g. `var clock: GameClock = GameClock.new(null)`, `var data: GameData = ...`, `var state: GameState = ...`. Type the lambda params (`_d: int`, `_p: int`/`bool`, `_s: int`, matching the signal signatures in `game_clock.gd`).
3. **`game/scripts/sim/placement.gd`, `line_tiles`:** `var dx: int`, `var dy: int`, `var step: int`. Use `absi()` instead of `abs()` so results stay `int`.
4. **`game/tests/test_placement.gd`:** `day_length` and `night_length` as `float`, `cost_wood` as `int` (all three occurrences), and `signal_handler` as `Callable`. Type its lambda's return as `-> void`.

## Acceptance criteria

- `clock` screenshot: the pressed speed button (1x by default) is clearly distinct from the other three, not just a subtle shade change.
- `grep -nE "var [a-z_]+ = " game/tests/test_game_clock.gd game/tests/test_placement.gd game/scripts/sim/placement.gd` returns nothing.
- All tests pass with no `SCRIPT ERROR` line. Smoke passes. The `hud` and `default` screenshots are otherwise unchanged.
- No stray files in the repo root or `game/`.
