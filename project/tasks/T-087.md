# T-087: Dawn Report panel + `dawn_report` scenario

Milestone: M4 | Type: code | Owner: gemini | Scenario: `dawn_report`
Depends on: T-024 (sim only: `NightLog`, `DawnReport.lines()`, and `GameState.last_dawn_report` with the
`night`/`unlocked`/`objective` keys). This is the UI half of the old T-024, split out after it was blocked.

## Goal

At each dawn of a running game, a centred panel shows the report from T-024 and pauses the game until the player
presses Continue or Enter. It never appears over Game Over or Victory. The panel only displays
`DawnReport.lines(report)`. Don't compute anything in the view.

test, which were broken. Write both from scratch as described below.

## What to do

1. **`scenes/ui/dawn_report.tscn`** (from the patch): a CanvasLayer on `layer = 15` with
   `Center/Panel/Margin/Content/{Title, Subtitle, Separator, Lines, Buttons/Continue}`. Keep it as it is: a 520 px
   panel with `assets/ui/panel.png` and no full-screen dim. Line labels use font size 18–20 so they're readable.
2. **`scripts/ui/dawn_report_panel.gd`** (`class_name DawnReportPanel extends CanvasLayer`), rewritten in the
   **GameOverScreen pattern**:
   - **No `@onready` vars and no `_ready()`.** Off-tree, `_ready` never runs, and that is what broke attempt 3's
     test. Resolve nodes with `get_node("Center/Panel/Margin/Content/...")` where you use them.
   - `bind(state)`: store `_state`, set `visible = false`, connect `state.dawn_processed` to `_on_dawn_processed`,
     and connect the Continue button's `pressed` to `_on_continue`.
   - `_on_dawn_processed(report)`: `call_deferred("_show_report", report)`. **It must be deferred.** `state.tick()`
     uses `clock.scale()`, which returns 0 while paused, so pausing synchronously would freeze the rest of a
     scenario's or test's setup ticks.
   - `_show_report(report)`:
     - If `_state.game_over`, return. A win or loss at the same dawn has already set it.
     - If the panel isn't already visible, remember `_was_paused = _state.clock.paused`.
     - Call `_state.clock.set_paused(true)`.
     - Title: `"DAWN: DAY %d" % int(report.get("day", clock.day))`. Subtitle: `"Night %d survived"` from
       `report["night"]`.
     - Rebuild the `Lines` rows from `DawnReport.lines(report)`. To clear the old rows, `remove_child` each one and
       then `queue_free` it, as GameOverScreen does.
     - Set `visible = true`.
   - `_on_continue()`: hide the panel. Call `_state.clock.set_paused(false)` only if `_was_paused` was false.
   - `_input(event)`: if visible and `event.is_action_pressed("ui_accept")`, call `_on_continue()` and then
     `get_viewport().set_input_as_handled()`. Space is part of `ui_accept`, so it closes the panel and doesn't
     toggle pause.
   - Static types everywhere.
3. **`main.tscn` / `main.gd`**: add a `DawnReport` instance after `VictoryScreen` and call
   `$DawnReport.bind(Game.state)` (both are in the patch).
4. **New scenario `dev/scenarios/dawn_report.gd`** (`extends Node`, `static func setup(main: Node) -> void`). Copy
   the structure of `dev/scenarios/victory.gd`:
   - `state.waves.enabled = false`. Clear trees, rocks and scrap around the CC the way victory.gd does.
   - Call `state.clock.phase_changed.emit(GameClock.Phase.NIGHT, state.clock.day)`, which starts the night log,
     then set `state.clock.phase = GameClock.Phase.NIGHT`.
   - Place 3 `wooden_wall`s near the CC with `state.buildings.add("wooden_wall", tile, true)`. Destroy one with
     `damage_building(w, w.hp)` and damage another by 60. Damage the CC by 40. Kill one survivor with
     `damage_survivor(s, s.hp)`.
   - Spawn 5 walkers near the base and kill each with `state.damage_zombie(z, 9999)`.
   - Set `state.clock.elapsed = float(state.data.balance("night_min_length")) - 0.1`, then call `state.tick(0.2)`.
     Dawn 2 fires with no hostiles left, and the panel shows on the next idle frame.
   - Centre `main.get_node("World/Camera2D")` on the CC (`cc.center_world()`).
5. **Tests: new `game/tests/test_dawn_report_panel.gd`**. Follow `test_game_over_screen.gd`: instantiate
   `res://scenes/ui/dawn_report.tscn`, call `bind(state)` with `GameState.new(GameData.load_default(), 1337)`, and
   free only the panel in `after_each`. **Never call `.free()` on GameState or GameData**, and never call `_ready()`.
   Call `panel._show_report(report)` directly, because the deferred call doesn't run off-tree. Use a report from a
   real dawn (`state.last_dawn_report` after ticking through night 1, `waves.enabled = false`). Test that:
   - the panel starts hidden, then after `_show_report` it is visible, `clock.paused` is true, the title is
     `"DAWN: DAY 2"`, the subtitle is `"Night 1 survived"`, and `Lines` has `DawnReport.lines(report).size()`
     children
   - `_on_continue()` hides the panel and unpauses the clock
   - a clock that was already paused before the report stays paused after Continue
   - showing two reports in a row leaves exactly the second report's rows (no stale children)
   - with `state.game_over = true`, `_show_report` leaves the panel hidden and doesn't pause the clock
   - binding and then emitting `dawn_processed` doesn't change `clock.paused` synchronously (it's deferred)

## Acceptance criteria

- At each dawn of a running game the panel appears and pauses the game. Continue, Enter or Space hides it and
  resumes the previous pause state. It never shows when `game_over` is true.
- The `dawn_report` screenshot at 1280x720 shows a readable panel with all of these:
  - `DAWN: DAY 2` and `Night 1 survived`
  - zombies killed, `Lost: <name>`, `Destroyed: Wooden Wall`, damaged buildings and the Command Center damage
  - food eaten
  - `New buildings unlocked: Storage, Watchtower, Workshop`
  - the objective line
  - a Continue button
- `test_dawn_report_panel.gd` covers the bullets above. The full suite passes with no SCRIPT ERROR.
- Import, smoke and all screenshots are clean. Scenarios that tick through a dawn now show the panel, which is
  acceptable. Every file is under 400 lines.

## Pitfalls

- Attempt 3's scenario used the id `wall` (it's `wooden_wall`) and the balance key `night_length` (it's
  `night_min_length`), and it waited on 7 live zombies, so dawn never came. Kill or never spawn every hostile
  before you advance the clock.
- Before finishing, run the `dawn_report` capture yourself, open the PNG and check that the panel is there.
- Don't put balance numbers in the view. Don't edit `scripts/autoload/dev_tools.gd`.
- T-025 (main menu) and T-085 (pause menu) also touch `main.tscn`/`main.gd`. Add your lines; don't reorder theirs.
