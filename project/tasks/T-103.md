## Pitfalls

- A 16 px texture in a 64 px TileSet is drawn at 16 px, not scaled. Scale the **layer**, not the texture or tileset.
- `Sprite2D.offset` is in the sprite's unscaled texture pixels. Get the sign right: negative y moves it up.
- Mouse picking and building placement use `Grid.world_to_tile`, not `ground.local_to_map`; keep it that way. If you
  find code that calls `ground.local_to_map`/`map_to_local`, convert through the layer transform.
- Buildings are not in the y-sorted `Props` node yet, so a tree directly south of a building may be drawn under it.
  T-104 merges buildings into one y-sorted layer; don't restructure the scene tree here.
- `hash(Vector2(...))` is deterministic; don't use `randi()` for visual variety.
- Night tint (`day_night_tint.gd`) multiplies everything. Check that the `night` scenario still reads, but tuning the
  tint is T-099, not this task.
