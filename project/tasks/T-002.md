# T-002: GameData loader + balance JSON files

Milestone: M0 | Type: code | Owner: gemini | Scenario: `default`

## Goal

Put every balance number from GDD §5–§10 into JSON under `game/data/`, and write one typed, Node-free loader (`GameData`) that every later system reads from.

## Files to create

- `game/data/buildings.json`, keyed by id: `command_center, wooden_wall, gate, shelter, farm, storage, watchtower, workshop, lumber_yard, turret, reinforced_wall, radio_tower`. Each entry has: `name` (display), `size` ([w, h] tiles), `cost` ({"wood": n, "scrap": n}, always both keys, 0 if unused), `hp`, `workers` (max, 0 if none), `unlock_day` (0 for command_center = start), `build_time` (work-seconds; 300 for radio_tower; choose sensible values for the others and log them in `project/assumptions.md`), `beds` (4 for command_center and shelter, else 0). Add effect fields where the GDD gives numbers: farm `food_per_farmer` 3; watchtower `guard_range_mult` 1.5; lumber_yard `chop_bonus` 0.5 and `radius` 6; turret `range_tiles` 5; workshop `ammo_per_scrap` 5; reinforced_wall `upgrade_from` "wooden_wall".
- `game/data/zombies.json`: `walker, runner, brute` with `hp, speed, damage, attack_rate, first_night`, plus `target_priority` ("command_center" / "survivors" / "structures"), `scale` and `tint` (from the ART_GUIDE zombie variants).
- `game/data/waves.json`: formula parameters, not 20 hand-written rows. Walkers `base 4, per_night 3`; runners `mult 2, offset 3`; brutes `mult 1, offset 7`; `sides_by_night` thresholds (1→1, 4→2, 10→3, 15→4); `spawn_window_fraction` 0.6; `final_night` 20 with `final_multiplier` 2 and `final_sides` 4.
- `game/data/balance.json`: starting resources (food 30, wood 60, scrap 15, ammo 40), starting survivors 4, survivor hp 50, `day_length` 150, `night_min_length` 45, food rules (eat 1 per survivor at dawn, hungry speed 0.5, leave after 2 hungry days, newcomers 1–2 when beds > pop and food ≥ 2×pop), map (size 48, tile 64, `clear_radius` 5, and `[min, max]` count ranges for trees/scrap/rocks for T-003; pick the ranges and log them), `repair_cost_fraction` 0.25, refunds before/after construction starts 1.0/0.5, zombie `survivor_attack_range` 1.5, `nights_to_win` 20.
- `game/scripts/sim/game_data.gd`: `class_name GameData extends RefCounted`.

## GameData API (minimum)

```gdscript
static func load_default() -> GameData          # loads res://data/*.json
func load_from_dir(dir: String) -> bool         # false + push_error on failure, never crashes
func building_ids() -> PackedStringArray
func get_building(id: String) -> Dictionary     # {} + push_error if unknown
func zombie_ids() -> PackedStringArray
func get_zombie(id: String) -> Dictionary
func balance(key: String, default_value: Variant = null) -> Variant
func wave_for_night(n: int) -> Dictionary       # {walker:int, runner:int, brute:int, sides:int, final:bool}
func buildings_unlocked_on(day: int) -> PackedStringArray   # all ids with unlock_day <= day
```

`wave_for_night(n)`: walkers = 4 + 3n; runners = max(0, 2(n−3)); brutes = max(0, n−7); sides from the thresholds. Night 20: all counts ×2, sides 4, `final: true`. Nights after 20 continue the base formula without doubling (log this assumption).

## Acceptance criteria

- All four JSON files exist and match GDD values.
- GameData has no Node/autoload dependencies and is usable from tests.
- `game/tests/test_game_data.gd` covers: every building has all required fields with correct types; values for at least wooden_wall, shelter, turret and radio_tower match the GDD; `wave_for_night(1)` = walker 7 / runner 0 / brute 0, sides 1; `(4)` = 16/2/0, sides 2; `(8)` = 28/10/1, sides 2; `(20)` = 128/68/26, sides 4, final true; `buildings_unlocked_on(1)` includes wooden_wall, gate, shelter, farm and excludes turret.
- Loading a malformed or incomplete file (write a temp file to `user://` in the test) returns false and pushes an error without crashing.
- Tests and the smoke run pass.

## Pitfalls

- A test that triggers `push_error` prints an `ERROR:` line. That's fine inside tests, but GameData must not print errors during the normal smoke run.
- Godot parses JSON numbers as float. Cast to int where ints are meant (`int(d["hp"])`).
- Don't add an autoload in this task. Later tasks decide that.
