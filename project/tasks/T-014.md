# T-014: Farmer and Crafter jobs (farms make food, the Workshop makes ammo)

Milestone: M2 | Type: code | Owner: gemini | Scenario: `production`
Depends on: T-013. Uses the T-012/T-013 job framework: `Jobs.tick`, `Survivor.Activity`, `work_uid`, `work_acc`, `job_timer`, `Grid.in_ring`, `Pathfinder.find_path_adjacent` and `GameState.resource_delivered` (which drives the floating "+N" popups). Read `builder_job.gd` and `gatherer_job.gd` first and follow their style.

**Scope change:** the original T-014 also covered eating at dawn, hunger, newcomers and beds. Those moved to **T-061**. This task is only the two workplace jobs.

## Goal

A survivor with the **Farmer** job walks to a complete Farm that has a free worker slot and produces food during the day. A survivor with the **Crafter** job walks to a complete Workshop with a free slot and turns 1 scrap into 5 ammo every craft cycle. Both show "+N food" / "+N ammo" popups. A building's worker count is shown in the info panel.

## Rules (all numbers from data)

- Worker slots: `buildings.json` `workers` (farm 2, workshop 1). A survivor **holds a slot** at building B when `s.job` is the matching job (FARMER for `farm`, CRAFTER for `workshop`) and `s.work_uid == B.uid`. Builders repairing a farm do **not** count.
- **Farm:** `food_per_farmer` (3) food per farmer per full day. While a farmer is FARMING and `clock.phase == DAY`: `s.work_acc += sim_dt * food_per_farmer / day_length`. Each time `work_acc >= 1.0 - 0.0001` (the epsilon absorbs float drift from many small steps): subtract 1, `resources.add("food", 1)`, `state.resource_delivered.emit("food", 1, b.center_world())`. So one farmer working a full 150 s day makes exactly 3 food.
- **Workshop:** new data key `"craft_time": 10` on `workshop` in `buildings.json` (work-seconds per cycle). While a crafter is CRAFTING and `clock.phase == DAY`: if `resources.get_amount("scrap") >= 1`, `s.work_acc += sim_dt`. When `work_acc >= craft_time`: subtract `craft_time`, `resources.take("scrap", 1)`, `resources.add("ammo", ammo_per_scrap)` (5), emit `resource_delivered("ammo", 5, b.center_world())`. If scrap is 0 the crafter stays assigned (keeps `work_uid` and its accumulated `work_acc`) with activity IDLE, and switches back to CRAFTING when scrap is available again.
- At **night** neither job produces (T-056 will send them to shelter). They keep their slot and activity; `work_acc` simply doesn't grow.

### Sim
2. `game/scripts/sim/production_job.gd` (new): `class_name ProductionJob extends RefCounted`.
   - `static func building_type_for(job: int) -> String`: FARMER → `"farm"`, CRAFTER → `"workshop"`, else `""`.
   - `static func workers_at(state: GameState, b: Building) -> int`: survivors holding a slot at `b` (rule above).
   - `static func tick(state: GameState, s: Survivor, sim_dt: float) -> void`. The state machine:
     - **Validate:** if `s.work_uid != 0` and the building is gone or not complete, clear `work_uid`, path and `work_acc`, set IDLE.
     - **Find a workplace** (`work_uid == 0`): respect `job_timer` like the other jobs. Candidates are the complete buildings of the right type with `workers_at < workers`, sorted by squared distance from `s.pos` to `center_world()` and then uid. Try at most 5: if already in the ring, take the slot and start working; otherwise `find_path_adjacent(s.tile(), b.origin, b.size)`, set `work_uid` (this reserves the slot while walking) and go WALKING. If none: IDLE and `job_timer = job_retry_interval`.
     - **Arrive:** WALKING and not moving → if in the building's ring, FARMING / CRAFTING; otherwise clear and retry.
     - **Work:** as in the rules above.

## Pitfalls

- Don't count `work_uid` matches without checking the job (builders also set `work_uid` on farms they repair).
- `day_length` comes from `state.data.balance("day_length", 150.0)`. Don't hard-code 150.
- Keep each file under ~400 lines. Static typing everywhere, including lambda parameters.
- Nodes in unit tests are never in the tree. Read "Testing scenes and Node scripts" in `game/tests/README.md` before testing `info_panel.gd`.
- Godot commands: only the ones in `project/ARCHITECTURE.md`. Always pass `--path game`. Scratch output goes under `project/runs/` or `game/*_out.txt`, never the repo root.
