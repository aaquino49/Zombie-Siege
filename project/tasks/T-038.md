# T-038: ResourceStore unknown-kind diagnostics + static typing for T-006 files

Milestone: M1 | Type: code | Owner: gemini | Scenario: `hud`
Depends on: T-006 (done). Runs before T-009, which builds on `hud.gd`.

## Goal

Small follow-up from the T-006 review. Make `ResourceStore` report bad cost keys consistently and bring the T-006 files up to ARCHITECTURE.md rule 3 (static typing everywhere). **Behaviour for valid kinds must not change.**

## Files to change

1. `game/scripts/sim/resource_store.gd`
   - `can_afford(cost)`: for any key not in `KINDS`, `push_error("Unknown resource kind: " + kind)`. Keep the current result: returns false if that unknown key's amount > 0, otherwise skips it.
   - `spend(cost)`: an unknown key with amount > 0 makes `can_afford` false, so nothing changes and it returns false. Remove the unused `any_spent` local.
   - `refund(cost, fraction)`: `push_error` for an unknown key, then skip it (the other kinds are still refunded).
   - Type every local: `var actual: int = mini(n, _amounts[kind])` (use `mini`, not `min`), `var amount: int = int(cost[kind])`, `var return_amount: int`, and loop vars `for kind: String in ...`.
2. `game/scripts/ui/hud.gd`: type every `@onready` var (`top_bar: NinePatchRect`, `food_icon: TextureRect`, `food_label: Label`, and so on; `day_label: Label`). Change `_load_texture(node: Node, path)` to `_load_texture(rect: TextureRect, path)` and give `top_bar` its own line (`top_bar.texture = load(path) as Texture2D` after `ResourceLoader.exists`), because `NinePatchRect` is not a `TextureRect`. Type `_labels` as `Dictionary` and cast on use: `(_labels[kind] as Label).text = str(amount)`.
3. `game/dev/scenarios/hud.gd`: `var store: ResourceStore = Game.state.resources`; rename the unused parameter to `_main`.
4. `game/tests/test_resource_store.gd`: type the member vars (`var _last_changed_kind: String = ""`, `var _last_changed_amount: int = -1`, `var _changed_count: int = 0`) and every local (`var data: GameData`, `var store: ResourceStore`, `var taken: int`).
5. Add to `game/tests/test_resource_store.gd`:
   - `test_spend_unknown_kind_changes_nothing`: `spend({"gold": 1})` returns false and all four amounts are unchanged.
   - `test_refund_skips_unknown_kind`: `refund({"wood": 10, "gold": 5}, 1.0)` adds 10 wood and leaves the others unchanged.

## Acceptance criteria

- `can_afford`, `spend` and `refund` call `push_error` on unknown kinds and never change amounts because of them. Covered by the two new tests.
- No untyped `var` declarations remain in `resource_store.gd`, `hud.gd`, `dev/scenarios/hud.gd` or `test_resource_store.gd`. Every var has `: Type`, or uses `:=` with an obvious type.
- `hud` screenshot unchanged: food 123 / wood 60 / scrap 0 / ammo 40, "Day 1", map visible below.
- All existing tests (including `test_resource_store_qa.gd` and `test_hud_qa.gd`) pass unchanged. Smoke passes.

## Pitfalls

- The new tests will print `ERROR: Unknown resource kind: gold`. That's expected. The test runner only fails on `SCRIPT ERROR`/`Parse Error`, and intentional `push_error` lines from negative tests are allowed (see ARCHITECTURE.md). Import, smoke and screenshot output must stay ERROR-free.
- Don't rename any public method or signal. T-009 and T-008 build on this API.
- Don't touch `dev_tools.gd`, `run_tests.gd` or `test_case.gd`.
