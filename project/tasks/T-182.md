# T-182: Polish: acid splash frame order and daytime acid colour

Milestone: M8 | Type: code | Owner: gemini | Scenario: `spitter_day` | skip QA

Found in T-165 a2 QA/review. In `game/scripts/world/combat_fx.gd` `_process`,
the acid splash loop calls `_frame(_acid_splash_age[i], ACID_SPLASH_LIFETIME,
...)` but `_frame`'s first parameter is REMAINING time (compare the blood
line which passes `_blood_remaining[i]`), so the splash plays 0 → 2 → 1 → 0
instead of the authored 0 → 1 → 2 once. By day the acid uses `Color.WHITE`
modulate and the pale yellow-green art reads cream in the `spitter_day`
capture.

## Scope fence

Touch only `game/scripts/world/combat_fx.gd`,
`game/tests/test_combat_fx.gd` (or the T-165 acid FX test file if named
differently — check first) and `project/assumptions.md`. Do NOT touch
`game/scripts/sim/`, `game/data/` or art files.

## Do

1. Pass remaining time to `_frame` for the splash:
   `_frame(ACID_SPLASH_LIFETIME - _acid_splash_age[i], ACID_SPLASH_LIFETIME,
   _acid_splash_frames.size())`.
2. In `CombatFx._on_phase_changed` (or wherever day/night acid modulate is
   set), give daytime acid a mild green bias, e.g. `Color(0.75, 1.0, 0.6)`,
   so glob and splash read as acid by day. Night behaviour unchanged.
3. Add/extend a unit test: after `acid_hit`, step `_process` through
   `ACID_SPLASH_LIFETIME` and assert splash atlas frames appear in order
   0, 1, 2 then hide; assert daytime acid modulate has g > r and g > b.

## Acceptance criteria

- Unit test: daytime acid modulate is green-biased; night unchanged.
- `spitter_day` capture at 1280x720 shows a visibly green glob and splash.
- All tests, import, smoke and screenshot clean.

## Pitfalls

  index changes.
