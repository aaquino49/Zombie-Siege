# T-179: Polish: a morning hint warns the first time spitters come tonight

Milestone: M8 | Type: code | Owner: gemini (Codex's coder stands in) | Scenario: `spitter_hint` (new) | skip QA

Starts after T-176 (same file). Spitters (T-164) arrive on night 7 and hit turrets and watchtowers from 3 tiles,
which walls alone don't stop. The forecast line says "1 spitter" (T-165), but nothing tells a new player what that
means. One one-shot tutorial hint does.

## Scope fence

Touch only `game/scripts/sim/tutorial_hints.gd`, the hint lists in `game/tests/test_tutorial_hints.gd` and
`game/tests/test_release_gate_qa.gd`, a new test `game/tests/test_spitter_hint.gd` and a new scenario
`game/dev/scenarios/spitter_hint.gd`. No UI script changes: `game/scripts/ui/hint_panel.gd` already shows any id
`TutorialHints.text()` knows.

## Do

1. In `TutorialHints.check()` (`game/scripts/sim/tutorial_hints.gd`), add a `spitters` hint after `radio`: shown
   once, by day, when tonight's forecast has spitters:
   `int(WaveSpawner.forecast(state.data, state.clock.day, state.difficulty_multipliers).get("spitter", 0)) > 0`
   (the same call `game/scripts/ui/hud.gd` `_refresh_forecast` uses, so Easy/Hard shift it with the waves).
   Mark it shown only when it is returned.
2. `TutorialHints.text("spitters")`: "Spitters come tonight. They stop 3 tiles out and spit acid at turrets and
   watchtowers. Post Guards and place turrets so they cover each other."
3. Update `test_tutorial_hints.gd` `test_hint_texts_valid` to include `spitters`, and `test_release_gate_qa.gd`
   (the day-8 step now also yields `spitters`: loop 4 times, expect `[..., "radio", "spitters"]`, `shown.size()` 8).
4. Scenario `spitter_hint`: Normal, day 7 morning, phase DAY (set difficulty and the day like
   `game/dev/scenarios/night_forecast.gd`, then `main.get_node("HUD").call("_refresh_forecast")`), and show the card
   the way `game/dev/scenarios/tutorial.gd` does: `Hints.set_enabled(true)` then `show_hint("spitters")`. The capture
   shows the hint card next to the forecast line that counts the spitter.

## Acceptance criteria

- Unit test: on Normal, `check()` returns `spitters` on day 7 by day (once), never on day 6, never at night; with
  Easy multipliers it appears on the first day whose forecast has a spitter, not before.
- `test_tutorial_hints.gd` and `test_release_gate_qa.gd` pass with the new hint.
- `spitter_hint` capture at 1280x720: the hint card is readable and doesn't cover the forecast line.
