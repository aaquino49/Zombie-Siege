## Context (real APIs, checked)

- `DawnRules.process(state)` returns `{day, food_eaten, hungry, left, arrived}`. Don't change it.
- `GameState._on_dawn` runs in this order: `DawnRules.process` → `_check_lose()` → `_check_win()` →
  `last_dawn_report = report` → `dawn_processed.emit(report)`. Add the extra report keys after
  `DawnRules.process` and before `_check_lose`.
- `GameClock` fires `phase_changed(phase, day)` at nightfall (`GameClock.Phase.NIGHT`) and after dawn (`Phase.DAY`).
  `dawn(day)` fires first, and `clock.day` is already incremented when it does.
- `GameData.load_default()`. `data.get_building(id)` returns a dict with `name`, `unlock_day` and `hp`. Also
  `data.building_ids()`, `data.balance("nights_to_win")` (20) and `data.balance("night_min_length")` (45).
- Building ids in `data/buildings.json`:
  - unlocked from the start: `command_center`, `wooden_wall` ("Wooden Wall", hp 150), `gate`, `shelter`, `farm`
  - day 2: `storage`, `watchtower`, `workshop`
  - day 3: `lumber_yard`. Day 4: `turret`. Day 6: `reinforced_wall`. Day 8: `radio_tower`
  - **Nothing unlocks on day 5 or day 7.**
- `state.buildings.all_of_type("command_center")[0]` is the CC. `state.radio_tower_complete()` already exists, and
  so does `state.buildings.count_of("radio_tower")`.
- `GameState`, `GameData`, `GameClock` and `NightLog` are **RefCounted. Never call `.free()` on them.**

## What to do (fixes to the applied files)

1. **`scripts/sim/night_log.gd`** (`class_name NightLog extends RefCounted`; it must not store a GameState)
   - Give every var and local a static type (`var dmg_count: int`, `var b: Building`, ...).
   - Remove the stored `night`. `summary(state)` returns `"night": state.clock.day - 1`, so dawn of day 2 gives 1.
   - `on_building_damaged(b, amount)`: if `b.type_id == "command_center"`, add the amount to `cc_damage` **only**.
     Don't put the CC's uid in `damaged_uids`, because the CC has its own line. Every other building goes into
     `damaged_uids`.
2. **`scripts/sim/game_state.gd`**
   - **Keep `clock.dawn.connect(_on_dawn)` where it was, at the end of `_init`.** The patch moved it to the top.
     Undo that move, and put `clock.phase_changed.connect(_on_phase_changed)` next to it at the end.
   - `damage_building`: compute `var lost: int = mini(amount, maxi(b.hp, 0))` and record damage only when
     `lost > 0`. Use a typed name: `var dname: String = str(data.get_building(b.type_id).get("name", b.type_id))`.
   - `_on_dawn`: give every local a static type.
     - `unlocked`: the ids whose `int(unlock_day) == clock.day`, sorted by id and mapped to display names. On day 2
       this is `["Storage", "Watchtower", "Workshop"]`.
     - `tower_state`: `"complete"` if `radio_tower_complete()`, otherwise `"building"` if
       `buildings.count_of("radio_tower") > 0`, otherwise `"none"`.
     - `objective`: `DawnReport.objective_text(clock.day, int(data.balance("nights_to_win")), tower_state,
       int(data.get_building("radio_tower").get("unlock_day", 0)))`.
3. **`scripts/sim/dawn_report.gd`** (`class_name DawnReport extends RefCounted`, static functions only)
   - **Remove `_get_tower_unlock_day()` and its FileAccess/JSON read.** Add a fourth parameter instead:
     `objective_text(day: int, nights_to_win: int, tower_state: String, tower_unlock_day: int) -> String`.
     Nights left is `nights_to_win - (day - 1)`. The texts are below. Write "1 night" for one, "N nights" otherwise.
     - none, day < unlock: `"Build the Radio Tower (unlocks day 8). 19 nights to go."`
     - none, day >= unlock: `"Build the Radio Tower. 12 nights to go."`
     - building: `"Radio Tower under construction. 12 nights to go."`
     - complete, left > 0: `"Radio Tower ready. Survive 3 more nights for rescue."` (`"1 more night"` for one)
     - complete, left <= 0: `"Radio Tower ready. Rescue comes at the next dawn."`
     - not complete, left <= 0: `"Nights are getting worse. Finish the Radio Tower!"`
   - `lines(report) -> Array[String]`: keep the patch's order and wording, and type the locals
     (`int(report.get(...))`). Skip any section that is empty or zero. The order:
     1. `Zombies killed: N`
     2. `Lost: names`
     3. `Destroyed: names`
     4. `Damaged: N buildings` (`Damaged: 1 building` for one)
     5. `Command Center took N damage`
     6. `Food eaten: N`
     7. `Hungry: …`
     8. `Left: …`
     9. `Arrived: …`
     10. `New buildings unlocked: …`
     11. the objective

## Tests: new `game/tests/test_dawn_report.gd` (`extends TestCase`)

Set up like `test_victory.gd` and `test_game_over_screen.gd`: `GameState.new(GameData.load_default(), 1337)`, then
`state.waves.enabled = false`. **Don't call `.free()` anywhere, and don't hand-build a `GameData`.** To reach dawn,
use the pattern from `test_game_over_screen.gd::test_dawn_loss_freezes_remaining_tick_time`: set
`clock.phase = NIGHT` and `clock.elapsed = float(balance("night_min_length")) - 0.1`, then call `state.tick(0.2)`.

- **Staged night:**
  - Start it with `state.clock.phase_changed.emit(GameClock.Phase.NIGHT, state.clock.day)`, which calls `begin`.
  - Spawn 3 walkers (`state.spawn_zombie("walker", pos)`) and kill each with `damage_zombie(z, 9999)`.
  - Place two `wooden_wall`s with `buildings.add("wooden_wall", tile, true)` on free, passable tiles. Destroy one
    with its full hp and damage the other by 30.
  - Damage the CC (at full hp) by 40. Kill one survivor with `damage_survivor(s, s.hp)`.
  - Reach dawn, then check `state.last_dawn_report`: `night == 1`, `zombies_killed == 3`,
    `buildings_destroyed == ["Wooden Wall"]`, `buildings_damaged == 1`, `cc_damage == 40`, and
    `survivors_killed` contains the survivor's name.
- **CC clamp**: damaging a CC that has 30 hp left by 100 gives `cc_damage == 30`.
- **Per night**: after the staged night, start another with `phase_changed.emit(NIGHT, day)`, kill 1 zombie and
  reach dawn. Expect `zombies_killed == 1`, an empty `buildings_destroyed` and `cc_damage == 0`.
- **Unlocked**:
  - dawn of day 2 → `["Storage", "Watchtower", "Workshop"]`
  - set `clock.day = 4` before the night → dawn 5 → `[]`
  - set `clock.day = 7` → dawn 8 → `["Radio Tower"]`
- **Objective**: every `objective_text` case above, including the singulars "1 night" and "1 more night".
- **lines()**:
  - A full report comes out in the documented order.
  - A report with only `food_eaten` and `objective` gives exactly 2 lines.
  - Zero or empty sections are skipped.
- **Existing keys**: the report still has `day`, `food_eaten`, `hungry`, `left` and `arrived` with DawnRules' values.
- **Reference cycles**: after a night with a log, `var wr := weakref(state)`, then `state = null`, then
  `wr.get_ref() == null`.
