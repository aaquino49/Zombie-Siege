# T-100: Design: rewrite ART_GUIDE.md for Ittai Manero 3/4-view pixel art

Milestone: M6 | Type: design | Owner: claude | Scenario: `default`

## Goal

First step of the M6 graphics overhaul (owner request R-5, GDD §16). Replace `project/ART_GUIDE.md` (written
for Kenney 90° vector art) with a guide for the new style, so Codex (mapping and gap-fill) and Gemini (swaps)
all work to one spec. This is a docs task. No game files change.

## Context

- Pack: Ittai Manero's "Zombie Apocalypse Tileset", already in the repo at `asset_library/ittaimanero/`:
  `sprites/` (532 PNGs in ~60 named category folders), the overview `Zombie Apocalypse Tileset Reference.png`
  (start here) and the source `Zombie Apocalypse Tileset.psd`.
- **The PNGs are exported PSD layers, trimmed to their content.** Names are `Zombie-Tileset---_0476_Capa-477.png`
  (Capa = layer) and sizes vary (14×16, 13×9, 16×16 ...). Animation frames in one folder can differ in size,
  so frames drawn as-is will jitter, and modular buildings are pieces with no position info. The guide must
  say how to recover a common frame box and anchor. Preferred: read layer offsets from the PSD (Python
  `psd-tools`) and re-pad each frame onto a fixed cell. Fallback: pad each frame bottom-centre onto the
  smallest common cell for its animation (e.g. 16×16 or 16×24), checked on a contact sheet.
- Current art: 64 px grid, Kenney sprites, survivors and zombies rotate to face. Project default texture
  filter is already Nearest (check `game/project.godot`, `rendering/textures/canvas_textures/default_texture_filter`).
- The audio section of the current guide (sources, CC0 rules, credits) still applies. Keep it.

## Do

Rewrite `project/ART_GUIDE.md` (keep it about 80–120 lines) with these sections:
1. **Style:** 16 px pixel art from the pack, 3/4 top-down view (roofs and front walls visible) everywhere.
   No Kenney vector art left once M6 ends. No painterly or AI-smoothed art.
2. **Scale and filtering:** source px × 4 = screen px on the 64 px grid. Integer scale only, Nearest filter,
   no mipmaps, no Lanczos, no fractional scale, no rotation of pixel sprites (except projectiles/tracers).
   Camera zoom may scale the whole world, which is fine.
3. **Footprints and anchoring:** 1×1 tile = 16×16 source. 2×2 building = 32×32 footprint, may be taller
   (roof overhang). Anchor tall sprites at the bottom of the footprint and y-sort. Trimmed-layer recovery as
   above.
4. **Animation:** characters and zombies use `AnimatedSprite2D` with one `SpriteFrames` `.tres` per
   character/variant. Names are `idle_<dir>`, `walk_<dir>`, `attack_<dir>`, `hurt_<dir>`, `death` with
   `<dir>` = down/up/left/right (left may be `flip_h` of right). Pick FPS defaults (walk 8, attack 10). Say
   what to do when the pack lacks a direction or state (flip, reuse the walk frame, or gap-fill).
5. **Entity map defaults:** walker → Skinny zombie, runner → Kid zombie, brute → Big zombie (Turret zombie
   spare). Survivors are recolors of the pack player. Farm → barn + crops. List the known gaps: turret, radio
   tower, watchtower, guard post, survivor variants.
6. **Palette:** use only colours from the pack. Codex extracts a palette PNG from the reference sheet into
   `asset_library/ittaimanero/palette.png` (T-101 or T-102). Recolors swap within it.
7. **Gap-fill process (order):** (a) edit or recombine pack pieces, (b) recolor, (c) hand-place 16 px pixel art
   in the pack palette with a Python PIL script kept in `asset_library/ittaimanero/gapfill/`. Image generation
   only as a reference, never shipped. Always a 4× contact sheet next to pack sprites.
8. **File layout:** `game/assets/pixel/{terrain,buildings,characters,zombies,props,fx,ui}/` with SpriteFrames in
   `game/assets/pixel/frames/`. Readable file names (`walker_walk_down_0.png` or packed strips), no `Capa-###`
   names in game/. Every file gets a row in `game/assets/ASSET_INDEX.md` (with its pack source file).
9. **Licence:** free for commercial use, credit appreciated, **no redistribution of the raw pack**. Ship only the
   sprites the game uses. Credit "Ittai Manero, Zombie Apocalypse Tileset (itch.io)" in `CREDITS.md`. The
   `asset_library/` copy stays out of the export (the export preset already only includes `game/`).
10. **Transition:** until each swap lands, Kenney art and pixel art coexist. Each swap task replaces one whole
    area (terrain, buildings, ...) so mixed styles never appear inside one area.
11. **Audio:** keep the current rules.

Then add a `project/decisions.md` entry (date, Claude, what, why) and, if anything in GDD §16 changes, update
it and log it in GDD §15.

## Acceptance criteria

- ART_GUIDE.md covers scale, filtering, view angle, footprints and anchoring (including trimmed-layer recovery),
  animation set and naming, palette, gap-fill process, file layout and licence for the new style. The audio
  rules are kept.
- No contradiction with GDD §16. Decision logged in decisions.md.
- No files under `game/` change.

## Pitfalls

- Open a few folders (Player Character Walking, Big Zombie Walking, Modular Barns, Terrain Variations) and check
  real frame sizes before writing the anchoring rule.
- Don't promise animations the pack doesn't have. Check which zombie types have damage/attack frames
  (`Damaged * Zombie Animation Frames`, `Knife Attack`, `Pistol Shooting`, `Shotgun Shooting`) and write the
  fallback rule.
