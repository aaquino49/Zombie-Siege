# T-202: Polish: weather readability (fog patch size, rain tag font)

Milestone: M10 | Type: code | Owner: gemini | Scenario: `weather_fog`

Follow-up from the T-194 review. No sim or data changes.

## Problem

1. In `game/scripts/world/weather_layer.gd` `_draw_fog`, the four fog patches
   are small (~11x7 blocks of 8 px) and read as scattered glyph-like specks
   rather than "a handful of large, pale patches"; in the `weather_fog`
   capture a player barely notices fog.
2. The top-bar RainTag (`hud.tscn` TopBar/Margin/HBox/DayArea/RainTag) has no
   `label_settings` and renders at `UiFont.SMALL` in a thin font that looks
   out of place next to DayLabel.

## Scope fence

Touch: `game/scripts/world/weather_layer.gd`, `game/scenes/ui/hud.tscn`
(RainTag label settings) and/or `game/scripts/ui/hud.gd`, new or updated
`game/tests/test_weather_view.gd` assertions only if needed for the font
check, the `weather_rain` / `weather_fog` scenarios if framing needs it, and
`project/assumptions.md`. No sim, data, save or range-logic changes.

## Do

1. Make fog patches larger and softer-stepped (e.g. 2-3x the footprint,
   rounder silhouette built from whole 4/8 px blocks, maybe 5-6 patches),
   keeping combined alpha <= 0.25 and drift <= 10 px/s, no per-frame
   allocations, no blur shaders. Patches still appear on fog nights only.
2. Give RainTag the same pixel font / LabelSettings style as the other
   top-bar labels (`UiFont` sizes only) and verify no overlap with DayLabel
   and IdleButton at 1280x720.
3. Captures at 1280x720: `weather_fog` shows clearly visible large fog
   patches while zombie rim, eyes and HP bars stay readable;
   `weather_rain` shows the readable rain tag with no overlap.
4. Run the full suite, import and 300-frame smoke.

## Acceptance criteria

- `weather_fog` capture at 1280x720 shows clearly visible large fog patches
  while zombie rim, eyes and HP bars remain readable.
- Fog combined alpha <= 0.25 and patches still only appear on fog nights.
- Rain tag uses the top-bar pixel font style at a `UiFont` size, readable in
  the `weather_rain` capture, with no overlap with Day label or Idle button
  at 1280x720.
- All tests pass, no SCRIPT ERROR, import/smoke clean.

## Pitfalls

- Don't touch `Weather`, `weather.json`, range math or save format.
- Fog must stay drawing-only (Node2D below UI) with short transition fades
  per the T-194 brief.
- Keep LF line endings and explicit static types.
