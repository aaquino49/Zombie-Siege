# T-019: Combat sim: guards, watchtowers, turrets, ammo

Milestone: M3 | Type: code | Owner: gemini | Scenario: `defense`
Depends on: T-018, T-068 (done).

## Goal

Defenders fight back. Guards take a post (a free watchtower, otherwise a spot next to the Command Center) and shoot
the nearest zombie in range; complete turrets shoot on their own. Every shot costs 1 ammo; with 0 ammo nobody shoots.
GDD §5, §6, §7.

This task is **sim + tests + a staging scenario**. Tracers, muzzle flashes, gun sprites, turret barrel rotation and the
"No ammo" HUD warning are T-077. Don't build them here.

## Numbers (data, not code)

- `balance.json`: `"guard_range_tiles": 5.0`, `"guard_fire_interval": 1.0`, `"guard_damage": 10`.
- `buildings.json` turret: keep `"range_tiles": 5`, add `"fire_interval": 0.5`, `"damage": 10`.
- Watchtower already has `"guard_range_mult": 1.5` (guard range 7.5 tiles on a tower).
- A walker (40 hp) takes 4 hits. Start ammo 40 covers night 1 (7 walkers = 28 shots).

## Work

1. **`Survivor`** (`scripts/sim/survivor.gd`): add `post_uid: int = 0` (manned watchtower uid), `post_tile: Vector2i =
   Vector2i(-1, -1)` (ground post), `on_tower: bool = false`, `fire_timer: float = 0.0`. Add `Activity.GUARDING`
   (label "Guarding") at the END of the enum.
2. **`Building`**: add `fire_timer: float = 0.0` and `aim: Vector2 = Vector2.UP` (last shot direction, for T-077).
3. **`GameState`**:
   - `signal shot_fired(from: Vector2, to: Vector2, is_turret: bool)` and `signal zombie_killed(z: Zombie)`.
   - `var zombies_killed: int = 0`.
   - `func damage_zombie(z: Zombie, amount: int) -> bool`: calls `zombies.damage(z.uid, amount)`; on a kill,
     `zombies_killed += 1` and emits `zombie_killed`. Returns true on kill.
   - `set_job`: if the survivor was a guard with a post, call `GuardJob.leave_post(self, s)` first.
4. **New `scripts/sim/combat.gd`** (`class_name Combat`, static funcs):
   - `nearest_zombie(state, from: Vector2, range_px: float) -> Zombie`: nearest by `distance_squared_to`, ties to the
     lower uid, `<= range_px`. No line-of-sight check (shots go over walls; log it in assumptions.md).
   - `try_fire(state, from: Vector2, range_px: float, damage: int, is_turret: bool) -> Zombie`: if ammo < 1 or no
     target, return null. Otherwise `resources.take("ammo", 1)`, `damage_zombie`, emit `shot_fired(from, target.pos,
     is_turret)`, return the target.
   - `tick_turrets(state, dt)`: for each **complete** turret (sorted by uid): `fire_timer += dt`; if
     `fire_timer >= fire_interval`, try to fire; on a shot `fire_timer -= fire_interval` and set `b.aim`; with no
     target or no ammo, clamp `fire_timer` to `fire_interval` (ready to fire the moment a target appears).
5. **New `scripts/sim/guard_job.gd`** (`class_name GuardJob`), called from `Jobs.tick` for `Job.GUARD`
   (day and night; guards never shelter, which `Jobs` already handles):
   - `pick_post`: nearest complete watchtower not held by another guard (`post_uid`), ties to the lower uid. If none,
     a ground post: the first tile of `state.cc_ring_tiles()` not used as another guard's `post_tile`
     (if all are taken, the last one).
   - Walking: watchtower → `pathfinder.find_path_adjacent(tile, origin, size)`; on arrival in the ring, set
     `on_tower = true`, `pos = tower.center_world()`, `path.clear()`, `activity = GUARDING`. Ground post →
     `find_path` to `post_tile`; on arrival `activity = GUARDING`. Retry with `job_retry_interval` if no path,
     like `ShelterRules`.
   - Shooting only while `activity == GUARDING`: same timer pattern as turrets with `guard_fire_interval`,
     range `guard_range_tiles * Grid.TILE` × `guard_range_mult` when `on_tower`. On a shot set `s.facing` toward the
     target. Hunger already slows `dt` in `Jobs`.
   - If the manned tower is removed/destroyed or incomplete: `leave_post` (put the guard on the first passable ring
     tile of the tower's footprint, like `ShelterRules.release`), then re-pick. If a watchtower is completed while a
     guard holds a ground post, re-pick so towers get manned (check once per second, not every tick).
   - `leave_post(state, s)`: clears `post_uid/post_tile/on_tower`, puts tower guards back on the ground.
6. **Protection on a tower**: in `ZombieAI.tick`, skip survivors with `on_tower` in `active_survivors` (same as
   sheltered). In `SurvivorStore.evict_from_solid`, skip `on_tower` survivors (they stand on a solid tile on purpose).
   `Pathfinder`/selection: an on-tower guard is still selectable (don't hide it).
7. `GameState.tick`: call `Combat.tick_turrets(self, step)` right after `Jobs.tick` (guards fire inside `Jobs.tick`).
8. **Scenario `game/dev/scenarios/defense.gd`** (daytime for readability; set `Game.state.waves.enabled = false` first
   if `waves` exists, since T-020 may land first): enclose the CC in a wooden-wall box like `zombies.gd`, add one complete
   watchtower and two complete turrets inside the box, assign 2 survivors as guards (one reaches the tower), spawn
   10 walkers just outside the east wall, tick until at least 3 zombies are dead and at least 3 remain, then pause.
   Camera on the east wall. HP bars should show damaged zombies; ammo in the HUD should be below 40.

## Tests: new `game/tests/test_combat.gd` (and `test_guard_job.gd` if it gets long)

- Range: a turret fires at a zombie 4.9 tiles away, not at 5.1 tiles; a guard on a tower hits at 7 tiles, a ground
  guard doesn't.
- Fire rate: a turret with a target in range for 2.0 s of 0.1 s ticks fires 4 shots (±1 for the first-shot rule you
  document); a guard fires 2 shots in 2.0 s.
- Ammo: each shot takes exactly 1 ammo; with ammo 0 nothing fires, no damage, no `shot_fired`.
- Target selection: nearest zombie chosen; equal distance → lower uid.
- Kills: 4 guard hits kill a walker, `zombies_killed` == 1, `zombie_killed` emitted once.
- Guard posting: a guard walks to and mans a free watchtower (`on_tower`, pos at tower centre); a second guard takes a
  ground post on the CC ring; zombies next to an on-tower guard don't damage it; destroying the tower puts the guard
  back on a passable tile and it re-posts; switching job away from Guard clears the post.
- An incomplete turret (blueprint) never fires.
- Existing tests unchanged and passing.

## Pitfalls

- Never draw from `state.rng` in combat (no randomness needed: no miss chance).
- `ResourceStore.take("ammo", 1)` returns the amount taken; check `get_amount("ammo") >= 1` first.
- Don't connect lambdas that capture `self`/state to store signals (T-072 reference-cycle rule). Use method Callables.
- Keep files under ~400 lines; static types everywhere (`var target: Zombie = ...`).
- Removing a zombie while iterating: `zombies.all()` returns a copy, so turret loops are safe; skip zombies already
  dead (`get_by_uid` is null) if you cache lists.
