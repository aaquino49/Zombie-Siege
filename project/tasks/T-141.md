# T-141: Polish: disable 'fi' ligature in the UI font ("finish" renders as "Anish")

Milestone: M6 | Type: code | Owner: gemini | Scenario: `how_to_play` | skip_qa

## Goal

In the T-111 How to Play capture (`project/runs/T-111/a1/qa_how_to_play.png`) the Goal line "finish the Radio Tower"
renders as "Anish". The UI font `game/assets/pixel/ui/font/siege_pixel.ttf` (theme default font in
`game/assets/pixel/ui/game_theme.tres`, line ~171) has a broken `fi` ligature glyph that the text shaper substitutes.
Turn standard ligatures off for the UI font so every Label, Button and RichTextLabel shows "fi" and "fl" as separate
letters.

## Do

1. Prefer a `FontVariation` resource (e.g. `game/assets/pixel/ui/font/siege_pixel_noliga.tres`) whose `base_font` is
   `siege_pixel.ttf` and whose `opentype_features` set `liga` (and `clig`) to 0. Make it the theme's `default_font`.
   Alternative if that doesn't work in Godot 4.7: set `opentype_feature_overrides` on the `FontFile` import. Pick one and
   say which in `work.json`.
2. Find any code or scene that loads `siege_pixel.ttf` directly (`grep -rn siege_pixel game/`) and point it at the
   same no-ligature font, so no screen bypasses the fix.
3. Don't change font sizes, colours, outlines or anything else in the theme. Keep the pixel import settings (no
   antialiasing, no hinting changes).
4. Test `game/tests/test_ui_font_ligatures.gd`: shape "finish" and "flag" with the theme default font through
   `TextServerManager.get_primary_interface()` (`create_shaped_text`, `shaped_text_add_string`,
   `shaped_text_get_glyph_count`) and assert the glyph count equals the character count (6 and 4). If shaping is not
   available headless, assert the font's `opentype_features` has `liga == 0` instead, and note it.

## Acceptance criteria

- `how_to_play` capture shows "finish" spelled correctly.
- A unit test proves ligatures are off for the theme default font (glyph count, or the feature flag).
- `test_menu_style` and the UiFont size tests still pass; all tests, import, smoke and screenshot clean.

## Pitfalls

- `opentype_features` keys are tag integers: use `TextServerManager.get_primary_interface().name_to_tag("liga")`.
- Don't touch `main_menu.gd`, `pause_menu.gd` or the menu screens (T-135 is on them) or `build_bar.gd` (T-132).
