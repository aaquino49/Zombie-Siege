# T-206: Endless wave damping key (nights 21+)

Milestone: M11 | Type: code | Owner: gemini | Scenario: `default`

Follow-up from T-189. Data + sim only; no bot, harness, UI or save changes.

## Problem

Nights 21+ reuse the base wave formula, so no data lever can tune endless
difficulty without retuning the whole campaign (GDD §21.1). The M11 balance
pass (T-207) needs that lever to exist first, or at least in parallel.

## Scope fence

Touch: `game/data/waves.json` (one new key, e.g. `endless_wave_mult`,
default 1.0), `game/scripts/sim/game_data.gd` (validation + default),
`game/scripts/sim/wave_spawner.gd` (`plan_night` / `wave_for_night` applies
it only for nights > 20), and wave/spawner tests.
Do NOT touch: the base formula for nights 1-20, `balance_bot.gd`,
`dev/balance_run.gd`, UI, scenarios, saves, or `weather.json`.

## Do

1. Add the endless-only key to `game/data/waves.json` (default 1.0 = no
   behaviour change). Validate it in `GameData` (must be a positive number;
   reject missing/negative the same way other wave keys are handled).
2. Apply it in `WaveSpawner` only for nights > 20: scale each spawn count
   (walkers, runners, brutes, spitters) by the key, rounding exactly one
   documented way (floor/round) and keeping spawn sides and timing unchanged.
3. Nights 1-20 stay byte-identical at any key value (early return or guard
   before scaling).
4. Unit tests: nights 1-20 unchanged with key 1.0 and with 0.8; nights 21+
   scale by the key (e.g. 0.8 gives fewer zombies than 1.0); same seed gives
   identical waves across runs.
5. Run the full suite, import and 300-frame smoke.

## Acceptance criteria

- Nights 1-20 spawn counts byte-identical to before (all existing wave,
  forecast and release-gate pins unchanged).
- Nights 21+ scale by the new key (unit test with 1.0 and one other value,
  e.g. 0.8).
- Same seed gives identical waves; full suite, import and 300-frame smoke
  clean.

## Pitfalls

- Never apply the key to nights <= 20 or to the night-20 Final Horde ×3.
- Keep the game's seeded RNG streams untouched; no new RNG.
- Keep LF line endings and explicit static types.
