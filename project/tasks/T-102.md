# T-102: ART: process mapped pack sprites into game/assets/pixel/ (padded frames, pieces, credits)

Milestone: M6 | Type: asset | Owner: codex | Scenario: `default`

## Goal

Owner request R-5, step 2 (part 1 of 2). Turn the approved T-101 mapping into game-ready pixel assets: every **mapped
pack sprite** (not the gaps) is padded, named readably and placed in `game/assets/pixel/`, ready for the Gemini swap
tasks (T-103 terrain, T-104 buildings, T-105 survivors, T-106 zombies, T-107 props/FX). Gap-fill art is a separate task
(**T-118**). No game code changes and nothing in the game looks different yet.

## Context

- Rules: `project/ART_GUIDE.md` (§2 scale, §3 anchoring/padding, §4 animation, §8 file layout, §9 licence).
- Approved mapping: `project/art_mapping.md` plus `asset_library/ittaimanero/mapping_manifest.json` (machine-readable rows,
  exact pack paths). Reuse `asset_library/ittaimanero/tools/mapping_data.py` rather than re-typing paths.
- Approved decisions from the T-101 review (`project/assumptions.md`): 16×16 **bottom-centre** padding
  (`x=(16-w)//2, y=16-h`), native side frames face **LEFT**, right = mirror of the padded left cell, walk playback
  0-1-0-2, reinforced wall = Terrain wall 65.

## Do

1. Write one re-runnable Pillow script `asset_library/ittaimanero/tools/process_pack.py` that reads the pack and writes
   `game/assets/pixel/`. Never pre-upscale; output native 16 px art.
2. **Characters and zombies** (`characters/`, `zombies/`): horizontal strips of fixed 16×16 cells, one PNG per animation
   and direction, for **all four directions** (`right` = whole padded `left` cell mirrored, so the code never needs
   `flip_h`):
   - `player_walk_{down,left,up,right}.png` (3 cells, source order; the code plays 0-1-0-2),
     `player_hurt_{dir}.png` (3 cells). The player body is the base for T-118's seven survivor recolours.
   - `walker_*`, `runner_*`, `brute_*` the same way from Skinny / Kid / Big (frame ranges in the art_mapping
     "Exact animation selections" table). Big stays 16×16; no extra scaling.
3. **Terrain** (`terrain/`): ground base (78) + variants and flower/tuft decals as 16×16 tiles; the native path set
   (66–77) as 16×16 tiles; and a **13-tile boundary atlas** in one strip `path_boundary.png` in the same order and
   meaning as the current T-071 atlas (`game/scripts/world/path_tiles.gd`: centre, 4 edges, 4 convex, 4 concave),
   derived as art_mapping "Terrain and barrier joins" describes (centre colour #77664e, 3 px edge bands).
4. **Resource nodes** (`props/`): trees and bushes, scrap (cars/tires) as single PNGs anchored bottom-centre.
   Rocks are a gap (T-118).
5. **Buildings** (`buildings/`): one assembled PNG per mapped building: command_center (32×48), shelter, farm (barn +
   crops), storage, workshop, lumber_yard (32×32 or taller per the mapping). For fences and walls, ship the join
   pieces so code can assemble them: `fence_{h,v,post,corner...}.png` and `gate_{closed,open}.png`, `wall_earth_*`
   for the reinforced wall. Name pieces after what they connect (N/E/S/W), as listed in the mapping. Turret, radio tower
   and watchtower are gaps (T-118).
6. **FX** (`fx/`): pistol/shotgun muzzle flash, knife slash, blood (380–384) strip, blood stains, corpses-with-flies
   (two 3-frame loops), smoke and explosion strips, all in fixed cells.
7. Run `godot --headless --path game --import`. Every new PNG must import with the project's Nearest filter, lossless,
   no mipmaps (check the generated `.import` files).
8. Add one `game/assets/ASSET_INDEX.md` row per file (file, purpose, pack source Capa numbers, processing). Add the
   credit to `CREDITS.md`: "Ittai Manero, Zombie Apocalypse Tileset (itch.io): free for commercial use, no
   redistribution of the raw pack; only processed sprites used by the game are included." Keep the Kenney credits
   (Kenney art stays until the swaps land).
9. Contact sheet at 4× nearest (`project/runs/T-102/a#/contact_sheet.png`, and one walk GIF per body
   `walk_check_<body>.gif`) that shows every new file, labelled, with each character's four walk strips playing 0-1-0-2.

## Acceptance criteria

- Every non-GAP row in `art_mapping.md` that a swap task (T-103–T-107) will use has a file in `game/assets/pixel/` (or
  is explicitly listed as procedural in the mapping). The work.json summary lists any row you skipped and why.
- Character/zombie strips: 16×16 cells, feet on the bottom row, four directions, no jitter on the walk GIFs.
- Only pack palette colours (`asset_library/ittaimanero/palette.json`) appear in the new PNGs. The script checks this
  and prints the result.
- All new files import cleanly with Nearest filtering. No `Capa-###` names under `game/`.
- `ASSET_INDEX.md` and `CREDITS.md` updated. No `.gd`/`.tscn` changes. Tests, import and smoke pass.

## Pitfalls

- Don't copy the raw pack or unused sprites into `game/` (licence: no redistribution).
- Pad first, then mirror the whole cell. Don't re-centre each frame on its silhouette.
- Don't create `SpriteFrames` `.tres` files or touch scenes. The swap tasks do that.
- Don't delete any Kenney file: the game still uses them.
