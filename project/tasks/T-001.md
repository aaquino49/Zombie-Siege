# T-001: Curate core Kenney art into game/assets

Milestone: M0 | Type: asset | Owner: codex | Scenario: `default`

## Goal

Copy the Kenney sprites the game needs for M1–M3 into `game/assets/<category>/` with clean snake_case names, so coders can reference stable paths. This is curation, not generation: only generate an image if nothing in the packs fits (resource icons are the most likely gap).

## Context

- Read `project/ART_GUIDE.md` first. Kenney packs are in `asset_library/kenney/` (outside Godot's view).
- Useful sources:
  - `kenney_top-down-shooter/PNG/Tiles/tile_*.png` (64 px ground, walls, crates, cars/debris; see `Preview.png`)
  - `kenney_top-down-shooter/PNG/<Character>/` for survivors: Man Blue, Man Brown, Man Old, Woman Green, Survivor 1, Soldier 1, Hitman 1 (use the `*_stand` and `*_gun` poses)
  - `kenney_top-down-shooter/PNG/Zombie 1/zoimbie1_stand.png`, `zoimbie1_hold.png`
  - `kenney_tower-defense-top-down/PNG/Default size/towerDefense_tile*.png` (grass/dirt/sand ground, trees, rocks, turret bases and barrels, bullets/rockets; see `Preview.png`)
  - `kenney_ui-pack/PNG/<Color>/`: pick ONE color family (recommended: Grey panels with one accent) and stick to it
  - `kenney_game-icons/PNG/White/` for UI glyphs (pause, play, fast-forward, hammer, etc.)
- Ignore `Thumbs.db`. Don't copy `Retina` or `Vector` variants.

## What to deliver

Folders and minimum contents (names are suggestions; keep them snake_case and descriptive):
- `game/assets/tiles/`: `grass_1..3.png` (variants), `dirt.png`, `road_*.png` (straight and corner at minimum). All 64×64.
- `game/assets/props/`: `tree_1..2.png`, `rock_1..2.png`, `scrap_1..3.png` (crates, barrels, car wreck/debris), `wall_wood.png` (anything that reads as a wall segment), `bush_berry.png` if one exists.
- `game/assets/characters/`: 7 survivors × (`_stand`, `_gun`), e.g. `survivor_blue_stand.png`; `zombie_stand.png`, `zombie_hold.png`.
- `game/assets/buildings/`: `turret_base.png`, `turret_barrel.png` (tower-defense pack). Other buildings come in T-007; leave them out.
- `game/assets/fx/`: `bullet.png`, `muzzle_flash.png` (or nearest equivalent).
- `game/assets/ui/`: panel, button (normal/hover/pressed), a small progress/health bar piece, all in one color family.
- `game/assets/icons/`: `icon_food.png`, `icon_wood.png`, `icon_scrap.png`, `icon_ammo.png` (24–32 px, readable on the UI panel), plus `icon_pause.png`, `icon_play.png`, `icon_fast.png`.
- `game/assets/ASSET_INDEX.md`: table `file | purpose | source (pack + original filename)` covering every file.
- `/CREDITS.md`: credit every Kenney pack used (CC0) and any generated art.
- Contact sheet at `project/runs/T-001/a<n>/contact_sheet.png`: all curated assets on a grass background, labeled outside the sprites.

## Acceptance criteria

- `game/assets/` contains tiles/, characters/, props/, buildings/, ui/, icons/, fx/ with the items listed above.
- Every ground tile is exactly 64×64; props, characters and icons have transparent backgrounds.
- `game/assets/ASSET_INDEX.md` lists every file with purpose and source.
- `CREDITS.md` credits the Kenney packs used (CC0).
- Contact sheet PNG produced in the run folder.
- `godot --headless --path game --import` succeeds and tests pass (`.import` files exist next to the PNGs).

## Pitfalls

- Don't copy whole packs. Only what's listed (roughly 60–90 files). Unused assets slow imports.
- Don't mix UI color families.
- Kenney's zombie files are spelled `zoimbie1_*`; rename them to `zombie_*` in game/assets.
- Run the import after copying so the `.import` files exist; the pipeline commits them.
