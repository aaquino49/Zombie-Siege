# T-060: Polish: roster panel width + JobOptions preload shadowing

Milestone: M2 | Type: code | Owner: gemini | Scenario: `ui_roster`
Depends on: T-015. A small follow-up from the T-015 review. Don't change selection, job or cancel logic.

## Goal and files

1. **Roster fits without a horizontal scrollbar** (`game/scripts/ui/roster_panel.gd`, `game/scenes/ui/roster_panel.tscn`). Today each row is a 100 px name Button + a job OptionButton + a 120 px activity Label, which is wider than the ScrollContainer.
   - Set the ScrollContainer's `horizontal_scroll_mode` to `SCROLL_MODE_DISABLED`.
   - Make the row fit: widen the panel to about 400 px, or shrink the name button to about 84 px and let the activity label expand (`size_flags_horizontal = SIZE_EXPAND_FILL`, `clip_text` stays true). Leave room for activity text like "Harvesting · Hungry" (T-061) and "Sheltered" (T-056).
   - The panel height should hug its content, up to about 420 px, instead of always reaching about 470 px.
2. **Shadowed global class.** `game/scripts/ui/info_panel.gd` and `roster_panel.gd` both declare `const JobOptions = preload("res://scripts/ui/job_options.gd")`, which shadows the global `class_name JobOptions`. Delete both const lines and use the global class directly.
3. Write any scratch Godot output under `project/runs/` or `game/*_out.txt` (gitignored), never as `*.txt` in the repo root.
