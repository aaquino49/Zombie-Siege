# T-192: Restore audio when victory continues into endless mode

Milestone: M9 | Type: code | Owner: gemini | Scenario: `victory` | QA via T-190 (do not skip: audio lifecycle regression)

GDD §19.1. T-186 review found the endless continuation is silent:
`AudioManager._on_game_won()` latches `_game_ended=true` and stops music,
but `VictoryScreen._keep_fighting()` never clears it, so phase music,
night/dawn cues and a later Game Over stinger stay suppressed until reload.

## Scope fence

Touch `game/scripts/audio/audio_manager.gd`, the endless continuation
integration (`VictoryScreen._keep_fighting()` path / GameState endless
notification), `game/tests/test_audio_manager.gd` or
`game/tests/test_endless.gd` (regression) and `project/assumptions.md`.
No sim, wave, save or balance changes. Terminal shutdown and fresh-run
behaviour stay intact.

## Do

1. Decouple "run ended" audio latch from the live-colony state: continuing
   into endless resumes the current phase music immediately (day or night
   loop) without replaying victory/rescue audio.
2. Restore normal cues after continue: next nightfall horn + night music,
   next dawn chime + day music, and a later loss stops music and plays
   Game Over exactly once.
3. Regression test via existing played counters: win -> keep fighting ->
   night -> dawn -> loss asserts music/cue counts (no victory replay, horn
   and chime fire, game-over fires once). Extend `test_audio_manager.gd`
   or `test_endless.gd`, whichever fits the harness.
4. `victory` capture unchanged apart from audio (panel still shows three
   readable buttons at 1280x720).

## Acceptance criteria

- Winning then Keep fighting immediately resumes current phase music
  without replaying victory audio.
- Next endless night/dawn play normal horn/chime + music switch; later
  loss stops music and plays Game Over exactly once.
- New lifecycle regression passes; existing audio + endless tests pass.
- Import, full tests and 300-frame smoke pass with no SCRIPT ERROR;
  import and smoke ERROR-free.

## Pitfalls

- Do not replay victory/rescue stingers on continue; only resume phase music.
- Keep `_game_ended` semantics for real terminal states (quit to menu,
  restart, fresh run).
- Keep LF line endings.
