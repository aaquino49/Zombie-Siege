# T-147: Difficulty 1: Easy / Normal / Hard data multipliers in the sim, checked with the balance bot

Milestone: M7 | Type: code | Owner: gemini | Scenario: `default`

## Goal

The sensible bot wins 9–10 of 10 seeds on the current balance, and T-128/T-136 showed we can't press it much harder
without breaking seed 1337's win. Rather than make the one game harder for everyone, add difficulty levels
(GDD §17.3). **Normal must stay exactly today's game** (every existing test and the release gate unchanged).

## Do

1. Data: a `difficulty` block in `game/data/balance.json`:
   `{"easy": {...}, "normal": {...all 1.0...}, "hard": {...}}` with keys `wave_size_mult`, `zombie_hp_mult`,
   `start_resource_mult`, `food_eaten_mult`. Starting values: easy 0.75 / 0.85 / 1.5 / 1.0; hard 1.3 / 1.2 / 0.75 / 1.0.
   Validate it in `GameData` (unknown level → warning and normal).
2. Sim: `GameState.new(data, seed, difficulty := "normal")` stores `difficulty` and passes multipliers where the
   numbers are read: wave counts in `WaveSpawner.plan_night` (round, min 1 where the base is ≥ 1), zombie HP on spawn,
   starting resources in `ResourceStore`. Rounding must make normal identical to today.
3. `SaveGame` (T-144): save and restore `difficulty`; old saves without it load as normal.
4. Bot: `dev/balance_run.gd -- --difficulty=easy|normal|hard` (default normal). Run 10 seeds
   (1337,1..9) `--strategy=both` for each level and put the table in `work.json` and `project/decisions.md`.
   Targets: easy ≥ normal on wins and min CC; **hard: sensible wins 4–7 of 10**, CC below 100% on at least 4 seeds,
   no hard loss before night 6. Tune only the hard/easy multipliers, at most 3 rounds.

## Acceptance criteria

- Normal: all existing tests pass unchanged, release-gate pin unchanged.
- Hard: 10-seed sensible wins 4–7, CC < 100% on ≥ 4 seeds; easy: wins ≥ normal; table in decisions.md.
- Save round trip keeps difficulty (test). Data validation test for unknown levels.
- All tests, import, smoke and screenshot clean.

## Pitfalls

- Don't touch the bot's strategy (`balance_bot.gd` decisions); only plumb the difficulty through.
- Starts after T-155, which changes `save_game.gd` (`rng_state` as a string, resources looped over `ResourceStore.KINDS`).
  Build the `difficulty` field on top of that version; old saves without `difficulty` load as normal.
- Don't change normal values to "fix" hard. If the hard target can't be met in 3 rounds, keep the closest variant and
  explain in decisions.md.
