# T-132: Polish: build-bar cost icons are small and low-contrast (scrap icon nearly invisible)

Milestone: M6 | Type: code | Owner: gemini | Scenario: `victory`

## Goal

After T-131 the build-bar cost row is a native 16 px `icon_wood.png` / `icon_scrap.png` next to a 22 px number. At
1× the icons read as tiny dark blobs on the dark button, and the scrap icon is almost invisible (see
`project/runs/T-131/a1/victory.png`: Watchtower, Workshop, Turret, Radio Tower). Make the cost icons recognisable.

## Do

1. In `game/scripts/ui/build_bar.gd` (`_rebuild_buttons`, cost row) switch to the 2× icons
   `res://assets/pixel/ui/x2/icon_wood.png` / `icon_scrap.png` (32 px) if the measured day-21 layout still fits
   1264 px (two rows are allowed by T-131's layout).
2. If the icons still don't read on the dark toggle background, add a light backing in code (e.g. a small
   `StyleBoxFlat` behind each icon in the button's light text colour at ~25% alpha). Don't edit the PNGs in this
   task; if the art itself must change, file it in `out_of_scope_bugs` for Codex.
3. The measured-width logic hard-codes `16.0` for the icon width: derive it from one constant (`COST_ICON_SIZE`)
   used for both the `TextureRect` size and the width calculation.
4. `game/dev/scenarios/victory.gd` calls the private `BuildBar._rebuild_buttons`: add a public `refresh()` (or rely
   on `day_started`) and use it.
5. Captures (1280×720, 1×) into `project/runs/T-132/a#/`: `victory`, `build_bar_day2`, `hud`.

## Acceptance criteria

- `victory` capture: wood and scrap cost icons clearly recognisable at 1× on every button, including dimmed
  (unaffordable) ones.
- Icon width in the width calculation comes from the same constant as the `TextureRect` size.
- `test_build_bar_qa.gd` day-2 and day-21 layout/content-fit tests still pass.
- No scenario calls an underscore-prefixed `BuildBar` method (`grep -rn "_rebuild_buttons" game/dev` is empty).
- All tests pass; import, smoke and screenshot clean.

## Pitfalls

- Cost row children need `mouse_filter = IGNORE` (T-131 pitfall; `qa_build_bar_input`).
- Leave `texture_filter` at the project default (Nearest). No non-integer scale on text.
