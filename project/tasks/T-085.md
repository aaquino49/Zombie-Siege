## Goal

GDD §11: "Pause menu (Resume, Restart, Quit to Menu, Volume)". Esc opens it during play, and Esc or Resume closes it.
Volume sliders (Master, SFX, Music) drive Godot audio buses and are remembered between runs, ready for the audio in
M5.

## What to do

1. **Audio buses**: `game/default_bus_layout.tres` with buses `Master`, `SFX` (send → Master) and `Music`
   (send → Master). In `project.godot`, add `[audio]` `buses/default_bus_layout="res://default_bus_layout.tres"`.
2. **`scripts/ui/audio_settings.gd`** (`class_name AudioSettings extends RefCounted`), all static:
   - `const PATH := "user://settings.cfg"`, `const BUSES := ["Master", "SFX", "Music"]`, default volume 0.8 for each.
   - `static func to_db(linear: float) -> float`: 0 → -80 dB (mute), otherwise `linear_to_db(clampf(linear, 0, 1))`.
   - `static func load_volumes(path := PATH) -> Dictionary` / `static func save_volumes(v: Dictionary, path := PATH)`
     with ConfigFile, section `audio`. A missing or corrupt file gives the defaults and never an error.
   - `static func apply(v: Dictionary) -> void`: sets each bus volume via `AudioServer.get_bus_index` (quietly skip a
     missing bus) and mutes the bus at 0.
3. **`game.gd`**: add exactly this, and change nothing else in the file (keep its LF line endings):
   ```gdscript
   func _ready() -> void:
   	AudioSettings.apply(AudioSettings.load_volumes())
   ```
   Use the `AudioSettings` class_name directly. No preload const is needed.
4. **`PauseMenu`**: `scenes/ui/pause_menu.tscn` + `scripts/ui/pause_menu.gd` (`class_name PauseMenu extends CanvasLayer`),
   layer 25. Copy `game_over.tscn`'s structure and styling: `Dim` (ColorRect, `mouse_filter = STOP`) /
   `Center` / `Panel` / `Margin` / `Content`, with title "PAUSED", a `Buttons` box (**Resume**, **Restart**,
   **Main Menu**) and a `Volumes` box with three labelled `HSlider`s (0–100, step 1) named `Master`, `SFX`, `Music`.
   `visible = false` in the scene.
   - **Follow the GameOverScreen/MainMenu pattern: no `@onready`, no `_ready`.** Do all wiring in `bind()` with
     `get_node(...)`. (Nodes in tests are never in the tree, so `_ready` never runs there.)
   - `bind(state: GameState, build_mode: BuildMode, selection: SelectionController, main_menu: CanvasLayer, dawn_report: CanvasLayer)`:
     store them, set `visible = false`, connect the buttons, load the saved volumes into the sliders
     (`value = v * 100`, set them **before** connecting `value_changed` so loading doesn't re-save), then connect
     each slider's `value_changed` to apply and save straight away.
   - Static pure rule:
     `static func can_open(game_over: bool, menu_open: bool, report_open: bool, build_active: bool, has_selection: bool) -> bool`
     is true only when all five are false. `game_over` is `state.game_over` (covers Game Over and Victory),
     `menu_open` is the Main Menu's `visible`, `report_open` is the Dawn Report's `visible`, `build_active` is
     `build_mode.active_type != ""`, and `has_selection` is `selection.selected_kind != ""`.
   - `_unhandled_input(event)`: on `cancel`, if the menu is open → `close()` and mark the input handled. Else, if
     `can_open(...)` → `open()` and mark the input handled. Otherwise do nothing, so BuildMode/Selection handle their
     own Esc (both already cancel/clear on `cancel`).
   - `open()`: remember `clock.paused`, then `set_paused(true)`, `locked = true`, `visible = true`.
     `close()`: `visible = false`, `locked = false`, then `set_paused(remembered)`. Don't hide the HUD or build bar.
   - Restart → `close()` then `Game.restart()`. Main Menu → `close()` then `Game.quit_to_menu()`.
5. **`main.tscn` / `main.gd`**: add a `PauseMenu` instance and, after the existing binds, one line:
   `$PauseMenu.bind(Game.state, $World/BuildMode, $World/Selection, $MainMenu, $DawnReport)`.
   Don't reorder or change the other binds.
6. **Scenario `dev/scenarios/pause_menu.gd`**: `static func setup(main: Node)`: get `main.get_node("PauseMenu")`,
   call `open()`, then set the Music slider (`.../Volumes/Music/...` HSlider) to 40 so the sliders are visibly live.
   **Restore the saved volumes afterwards**, or set the slider with `set_value_no_signal(40)`, so the screenshot run
   doesn't change `user://settings.cfg`.

## Acceptance criteria

- Esc in normal play opens the pause menu and freezes the game. Space/1/2/3 do nothing while it's open. Esc/Resume
  close it and restore the previous speed/pause. Esc still cancels build mode and clears the selection first.
- It never opens over Game Over, Victory, the Main Menu or the Dawn Report.
- Restart and Main Menu work from the pause menu. The volume sliders change the bus volumes and persist across runs.
- `pause_menu` screenshot at 1280x720 shows the panel, readable, over the day-1 map. All other screenshots are
  unchanged.
- All tests pass with no SCRIPT ERROR. Import, smoke and screenshots are clean (no audio-bus errors in headless
  runs).
- `git status` shows no changes to `dev_tools.gd` and no scratch files (root `*.txt`, `game/test*.gd`).

## Pitfalls

- Headless runs use a dummy audio driver. `AudioServer` calls must not print errors there.
- Don't use `get_tree().paused`. The game pause is the GameClock, and DevTools needs the tree running.
- `clock.locked` blocks `set_paused(false)`, so in `close()` unlock first, then restore.
- Don't touch `dev_tools.gd`, `run_tests.gd` or `test_case.gd`. Delete every scratch file you create before
  finishing.
