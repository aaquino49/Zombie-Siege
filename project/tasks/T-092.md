# T-092: Title art behind the main menu + app icon in project settings

Milestone: M5 | Type: code | Owner: gemini | Scenario: `main_menu`
Depends on: T-031 (done: `game/assets/ui/title_art.png` 1280x720, opaque, text-free, with the centre
(320,195)-(960,525) kept clear for the menu; `game/assets/icon/icon.png` 256x256 and `icon.ico`).

## Goal

The main menu shows the title art instead of the dimmed live map, and the game window/exe uses our icon.

## What to change

1. `game/scenes/ui/main_menu.tscn`: add a `TextureRect` named `TitleArt` as the **first child** of the `MainMenu`
   CanvasLayer, so it's behind `Dim`. Use full-rect anchors, `texture = res://assets/ui/title_art.png`,
   `expand_mode = EXPAND_IGNORE_SIZE` (1) and `stretch_mode = STRETCH_KEEP_ASPECT_COVERED` (6), and
   `mouse_filter = MOUSE_FILTER_IGNORE`. It's part of the MainMenu layer, so it shows and hides with the menu, and
   nothing else changes when the menu closes.
2. Lower `Dim`'s colour alpha from 0.55 to about 0.25 so the art reads while the panel text stays readable. Don't
   change the panel, buttons or `main_menu.gd` logic.
3. `game/project.godot`: under `[application]`, set `config/icon="res://assets/icon/icon.png"`. Leave the export
   preset and `.ico` to T-033 (Windows export).

## Tests

- Add a test (a new `game/tests/test_main_menu_art.gd`, following the off-tree patterns in
  `test_pause_menu.gd`/`test_restart.gd`): instantiate `main_menu.tscn`, assert `TitleArt` exists, is a
  `TextureRect`, sits before `Dim` in child order, uses the `title_art.png` texture (`resource_path`) and
  `STRETCH_KEEP_ASPECT_COVERED`, and ignores the mouse.
- Assert `ProjectSettings.get_setting("application/config/icon") == "res://assets/icon/icon.png"`.

## Acceptance criteria

- The `main_menu` scenario screenshot shows the title art filling 1280x720 behind a readable menu panel (title,
  tagline and both buttons legible).
- `project.godot` `config/icon` points to `res://assets/icon/icon.png`.
- The new test passes. Existing tests (`test_restart.gd`, `test_pause_menu.gd`, `test_victory.gd`,
  `test_game_over_screen.gd`) still pass. Import, smoke and the default screenshot are clean (the default
  scenario skips the menu, so it must look unchanged).

## Pitfalls

- Don't touch `dev_tools.gd`, `run_tests.gd`, `test_case.gd` or other menus.
- Don't add `@onready`/`_ready` to `main_menu.gd`. No script change is needed at all.
- Editing `project.godot` by hand: change only the one key and keep everything else, including the autoload
  order, byte for byte.
