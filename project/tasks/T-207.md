# T-207: Design: M11 balance pass v5 (repeat harness, forecast-aware bot)

Milestone: M11 | Type: design | Owner: claude | Scenario: `default`

Data-only balance pass. No bot, harness, sim or UI changes; file follow-ups
instead of widening scope.

## Problem

T-204's v3.2 forecast-aware bot regressed Normal sensible 6/3/1 to 5/2/3 and
turned the seed-1337 win into a 2854.50 s night-20 loss through guard ammo
use (M10 report). T-197 showed single runs per seed measure coin flips, so
this pass tunes with win-rate majorities and sets the T-206 endless key from
real post-20 bot runs.

## Scope fence

Touch: `game/data/*.json` (waves, balance, weather, zombies as needed),
affected test pins (list old -> new), and `project/decisions.md` (version,
before/after tables, reasons). Optionally `project/assumptions.md`.
Do NOT touch: `game/scripts/sim/balance_bot.gd`, `game/dev/balance_run.gd`,
any other sim file, UI, scenarios or saves.

## Do

1. Tune with the T-203 `--repeat=K` harness (K >= 3): per-seed majority
   outcome (won/survived/lost) is the signal, not single runs. Use the v3.2
   forecast-aware bot, Normal + Hard, sensible at minimum, 10 seeds.
2. Repair the T-204 Normal regression first (Normal sensible back to >= 6
   won, 0 lost), then set the T-206 endless key from real post-20 bot runs
   (endless nights must stay threatening but survivable past night 25 on at
   least one seed).
3. Sequencing: T-206 may merge mid-pass. The final verification matrices
   must run against merged main; re-run them if anything data-adjacent
   merges after your last matrix.
4. Record 10-seed before/after tables (Normal + Hard, sensible,
   --repeat >= 3 majority per seed) in `project/decisions.md`, with moved
   test pins listed old -> new. Any missed target gets a reason (per T-128
   precedent), never a silent re-roll.
5. Run the full suite, import and 300-frame smoke.

## Acceptance criteria

- 10-seed before/after tables (Normal + Hard, sensible, --repeat >= 3
  majority outcome per seed) recorded in `project/decisions.md`.
- Targets: Normal sensible >= 6 won and 0 lost, Hard 4-7 won, none loses
  with loss-row night 4 on every seed; any miss recorded with a reason
  (per T-128 precedent), not re-rolled silently.
- Moved test pins listed old -> new; full suite, import and smoke clean.

## Pitfalls

- Majority outcome per seed, not best-of-K. Single-run tuning is no longer
  credible.
- Small data steps; the T-204 loss came from ammo economy, not wave size.
- Keep LF line endings.
