# T-094: Polish: survivors with no reachable shelter try another shelter and warn the player

Milestone: M6 | Type: code | Owner: gemini | Scenario: `night_shelter`

## Goal

When a survivor can't reach its chosen shelter at nightfall (walled off by the player's own buildings), it
retries the same shelter forever and stands outside all night. Make it try other shelters first, and if none
is reachable, tell the player once per night.

## Context

- `game/scripts/sim/shelter_rules.gd`:
  - `pick_shelter(state, s)` returns the nearest complete building with free beds, else the Command Center.
  - `tick(state, s, dt)`: when `s.path` is empty after `state.pathfinder.find_path_adjacent(s.tile(), b.origin, b.size)`,
    it sets IDLE and waits `job_retry_interval`, keeping the same `shelter_uid`.
  - `release(state, s)` drops the claim.
- Seen in T-027's probe on seed 3, night 11: Alex at (27,27) and Trent at (18,18) stayed outside all night.
- Existing tests: `game/tests/test_shelter_rules.gd`, `test_shelter_rules_qa.gd`. Scenario:
  `game/dev/scenarios/night_shelter.gd`.
- GameState signals live at the top of `game/scripts/sim/game_state.gd`. The HUD already shows a red "No ammo"
  warning (`game/scripts/ui/hud.gd` `_refresh_ammo_warning`).

## Do

1. **Sim:** give `pick_shelter` an optional `exclude: Dictionary` (uids to skip). In `tick`, when the path is
   empty, add `b.uid` to a per-survivor "unreachable this night" set (a field on `Survivor`, cleared at dawn or
   when the night starts). Then `release` and pick again, skipping excluded uids. Try the CC last, as now.
   If every candidate is excluded, keep the survivor IDLE outside, with the normal retry interval, and stop
   re-picking until the next retry.
2. **Signal:** add `signal survivor_unsheltered(s: Survivor)` to GameState, emitted **once per survivor per night**
   when they run out of reachable shelters.
3. **View:** show a short HUD warning `"<name> can't reach shelter"` (reuse the HUD warning label style, or a
   floating label above the survivor) for about 5 s. Keep it small. No new modal.
4. Tests (sim only): (a) the nearest shelter is fully walled off, and a second reachable shelter exists, so
   the survivor ends up sheltered in the second one. (b) No shelter is reachable, so the survivor stays
   outside and `survivor_unsheltered` fires exactly once during the night. (c) The next night, the exclusion
   set is reset.

## Acceptance criteria

- Sim test: a survivor whose nearest shelter is walled off walks to another reachable shelter at nightfall.
- Sim test: with no reachable shelter, the survivor stays outside and the warning signal fires once per night.
- Sim test: exclusions reset at the next night.
- All tests pass. Import, smoke and screenshots are clean. The night_shelter screenshot is unchanged (no warning
  in the normal case).

## Pitfalls

- Keep the sim deterministic. Iterate buildings in uid order and don't use wall-clock time.
- Bed counting (`beds_held`) must not leak claims. Always `release` before re-picking.
- Don't change daytime job logic or the dawn exit flow.
