## Pitfalls

- `HBoxContainer` inside a `Button` doesn't get mouse events filtered by default: set `mouse_filter = IGNORE` on the
  cost row and its children, or clicks stop reaching the button (see `qa_build_bar_input` scenario).
- `TextureRect` defaults to linear filtering if the node overrides it; leave `texture_filter` at the project default
  (Nearest).
- Don't put any text under a non-integer `scale` (T-122 rule). Keep every font size a `UiFont` constant.
- Button widths that aren't whole pixels blur nothing, but text positions should stay integer: round widths.
- T-122 a1/a2 failed on clipped captions because a fixed button height ignored the font's 28 px line height at
  BODY. Size rows from the font's real `get_height()`, not from 22.
