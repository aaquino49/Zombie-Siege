# T-011: Survivor sim + movement

Milestone: M2 | Type: code | Owner: gemini | Scenario: `survivors`
Depends on: T-008 (GameState, BuildingStore, WorldMap occupancy). First M2 task. T-012 (construction), T-013 (gathering) and T-015 (selection/roster) build on it.

## Goal

The colony starts with 4 named survivors standing next to the Command Center. Each survivor is a sim object that can be ordered to walk to a tile. It follows an `AStarGrid2D` path around trees, rocks, scrap and buildings at a data-driven speed that respects pause and 1x/2x/3x. A thin view layer draws one sprite per survivor. Jobs are only a field for now; the job behaviour comes in T-012/T-013/T-014.

## Files

### Sim (pure logic, `scripts/sim/`, RefCounted, no Nodes)

1. `game/data/balance.json`: add `"survivor_speed": 96` (px per sim-second), and
   `"survivor_names": [...]` with 24 short first names (mixed), and `"survivor_variants": ["blue", "brown", "green", "old", "survivor", "hitman", "soldier"]` (these match `game/assets/characters/survivor_<variant>_stand.png`). Don't add them to `GameData._validate_balance`'s required keys (the negative-test fixtures don't have them); read them with `data.balance(key, default)`.
2. `game/scripts/sim/survivor.gd`: `class_name Survivor extends RefCounted`.
   - `enum Job { IDLE, GATHERER, FARMER, BUILDER, CRAFTER, GUARD }`
   - `var uid: int`, `var name: String`, `var variant: String`, `var hp: int`, `var max_hp: int`, `var job: int = Job.IDLE`, `var pos: Vector2` (world px, tile centre when standing), `var path: Array[Vector2i]` (remaining tiles, next first), `var target: Vector2i`, `var facing: Vector2 = Vector2.RIGHT`.
   - `func tile() -> Vector2i` (`Grid.world_to_tile(pos)`), `func is_moving() -> bool` (`not path.is_empty()`).
3. `game/scripts/sim/pathfinder.gd`: `class_name Pathfinder extends RefCounted`, wraps one `AStarGrid2D`.
   - `_init(map: WorldMap)`: `region = Rect2i(0, 0, map.size(), map.size())`, `cell_size = Vector2(Grid.TILE, Grid.TILE)`, `diagonal_mode = AStarGrid2D.DIAGONAL_MODE_ONLY_IF_NO_OBSTACLES`, `update()`, then mark solids. Connect `map.changed` to set a `_dirty` flag. **Don't rebuild inside the signal.** Rebuild lazily at the next query.
   - Solid = `not map.is_passable(t)`, **except gate tiles** (`map.building_at(t) == "gate"`), which survivors can walk through (GDD §7).
   - `func find_path(from: Vector2i, to: Vector2i) -> Array[Vector2i]`: `get_id_path`. Returns `[]` if either end is solid or there's no path. The result excludes `from`.
   - `func find_path_adjacent(from: Vector2i, origin: Vector2i, size: Vector2i) -> Array[Vector2i]`: the shortest path to any passable tile in the 1-tile ring around the rect (8-neighbourhood). Used to walk up to a tree, the CC or a blueprint. Returns `[]` if none is reachable. If `from` is already in the ring, return `[]` and let the caller treat it as "arrived" (document this in a comment).
4. `game/scripts/sim/survivor_store.gd`: `class_name SurvivorStore extends RefCounted`.
   - `signal survivor_added(s: Survivor)`, `signal survivor_removed(s: Survivor)`
   - `func add(p_name: String, variant: String, t: Vector2i) -> Survivor` (hp/max_hp from `survivor_hp`, `pos = Grid.tile_to_world(t)`), `func remove(uid: int) -> void`, `func get_by_uid(uid: int) -> Survivor`, `func all() -> Array[Survivor]`, `func count() -> int`.
   - `func tick(sim_dt: float, pathfinder: Pathfinder, map: WorldMap) -> void`: moves each moving survivor toward `Grid.tile_to_world(path[0])` by `speed * sim_dt`. **Carry leftover distance** across tiles in a while-loop, so the speed is exact at any frame rate. Pop a tile when it's reached. Update `facing` to the move direction. If the next tile has become impassable (a wall was placed), re-path once to `target` with `find_path`. If there's no path, clear `path` and stop on the current tile's centre.
   - No allocations in the per-frame loop beyond the occasional re-path (no new arrays/dicts per survivor per tick).
5. `game/scripts/sim/game_state.gd`:
   - `var pathfinder: Pathfinder`, `var survivors: SurvivorStore`. Create them in `_init` **after** the CC is added.
   - Spawn `start_survivors` (4) on distinct passable tiles of the ring around the CC footprint. Take them in a fixed order (sort by y then x) so it's deterministic. Names: shuffle `survivor_names` with a `RandomNumberGenerator` seeded `map_seed + 1` and take the first N. Variants cycle through `survivor_variants`.
   - `func order_move(uid: int, t: Vector2i) -> bool`: sets `target` and `path`. Returns false (and changes nothing) for an unknown uid or an unreachable/solid tile.
   - `tick(delta)`: after `clock.advance(sim_dt)`, call `survivors.tick(sim_dt, pathfinder, map)`. Pause (sim_dt 0) means no movement.

## Acceptance criteria

- New game (seed 1337): exactly 4 survivors with unique non-empty names, hp == max_hp == `survivor_hp` (50), on 4 distinct passable tiles in the ring around the CC. The same seed gives the same names and tiles.
- Pathfinder tests: a path between two free tiles never steps on an impassable tile, each step is an 8-neighbour of the previous, and there's no diagonal corner-cutting next to an obstacle. After `try_place("wooden_wall", ...)` across a known path, the next `find_path` avoids the wall. A gate tile is walkable. A target that's solid or fully walled off returns `[]`. `find_path_adjacent` to the CC ends on a tile touching the CC footprint.
- Movement tests: `order_move` 5 tiles straight east on free grass: still moving after `tick` totalling 3.0 s at 1x (in 0.1 s steps), and arrived exactly on the target tile centre by 3.5 s (5 × 64 / 96 ≈ 3.33 s). At 2x it's arrived by 1.75 s. While paused, `tick(1.0)` doesn't change `pos`. A wall placed on the next path tile mid-walk makes it re-path and still arrive. `order_move` to a tree tile returns false.
- Layer tests: after `bind`, one Sprite2D child per survivor. After moving a survivor's `pos` and calling `sync()`, the sprite position matches. `survivors.add(...)` adds a child and `remove(uid)` removes it (child count correct immediately).
- `survivors` screenshot: the buildings from `buildings_placed`, 4 survivor sprites (3 standing by the CC, 1 away from them), drawn on top of the ground and buildings, at a sensible size (about half a tile).
- All tests pass with **no `SCRIPT ERROR` line** in the test output; smoke passes. `default`, `buildings_placed`, `hud`, `clock` still look right (survivors standing by the CC there is expected).
- Static typing on every var/param/return. Every new file stays under ~250 lines. No stray files in the repo root or `game/`.

## Pitfalls

- `AStarGrid2D` needs `update()` after changing `region`/`cell_size` and **before** `set_point_solid`. `get_id_path` on a solid end point prints an error in some versions, so check `is_point_solid` first and return `[]`.
- `GameState._init` order matters: map → CC → pathfinder → survivors. Building placement calls `map.occupy`, which emits `changed`. That's how the pathfinder learns about new walls.
- Survivors don't occupy tiles. Don't call `map.occupy` for them, and don't change `Placement`.
- Never use `Engine.time_scale` or `SceneTree.paused`. All movement time comes from the `sim_dt` passed into `tick`.
- Godot commands: only the ones in `project/ARCHITECTURE.md`. Always use `--path game`, and never `-s` on a non-SceneTree script (the watchdog kills hung runs after 15 min and you lose the time).
