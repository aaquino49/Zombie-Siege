# T-013: Gathering + drop-off

Milestone: M2 | Type: code | Owner: gemini | Scenario: `gathering`
Depends on: T-012. It uses T-012's job framework: `Jobs.tick`, `Survivor.Activity`, `work_uid`, `job_timer`, `GameState.set_job` and `Grid.in_ring`. Read those files first.

## Goal

Gatherers keep the colony supplied. A survivor with the **Gatherer** job and a chosen resource (wood or scrap):
1. walks to the nearest tree or scrap pile,
2. harvests it over time,
3. carries a load back to the nearest complete Command Center or Storage,
4. adds the load to the ResourceStore, and a floating "+10 wood" popup appears.

Nodes deplete and disappear. A complete Lumber Yard makes wood chopping 50% faster within 6 tiles. Starting jobs become 1 Builder, 2 wood Gatherers and 1 scrap Gatherer, so the real game produces resources without any UI.

### Sim
2. `world_map.gd`:
   - `func nodes_of(occupant: int) -> Array[Vector2i]`: tiles in `_node_amounts` whose occupant matches.
   - `harvest()` should emit `changed` **only when the node is depleted** (the occupancy changes). Today it emits on every unit, which makes the pathfinder rebuild all 2304 points and the world view rescan its props. Update the expectation in `test_world_map_qa.gd::test_generated_tree_and_scrap_harvest_and_changed_signal` from `changes_before + 2` to `changes_before + 1`, with a comment.
3. `survivor.gd`:
   - `var gather_kind: String = "wood"`, `var carry_kind: String = ""`, `var carry_amount: int = 0`, `var work_tile: Vector2i = Vector2i(-1, -1)` (the node being harvested).
   - Extend `job_from_name`, or add a small parser, so `"gatherer_wood"` and `"gatherer_scrap"` mean GATHERER with that kind.
4. `gatherer_job.gd` (new): `class_name GathererJob extends RefCounted`, `static func tick(state: GameState, s: Survivor, sim_dt: float) -> void`. The state machine:
   - **Need a node** (no valid `work_tile`, or the node is depleted) and `carry_amount < capacity`:
     - Candidates are `map.nodes_of(TREE or SCRAP)`, sorted by squared distance from `s.tile()`. Try at most 5 with `Grid.in_ring` / `find_path_adjacent(s.tile(), node, Vector2i.ONE)`. The first reachable one becomes `work_tile`, and the survivor goes WALKING (or straight to HARVESTING if already in the ring).
     - If none is reachable: deliver any carried load if it has one, otherwise wait `job_retry_interval` as IDLE.
   - **HARVESTING** (in the ring of `work_tile`):
     - `s.work_acc += sim_dt * mult`. `mult` is `1 + chop_bonus` for wood when any *complete* `lumber_yard` has its centre within `radius` tiles (Euclidean, tile units) of the node tile. Several yards don't stack. Scrap always uses 1.
     - Each time `work_acc >= gather_time_<kind>`: subtract it, `carry_amount += map.harvest(work_tile, 1)`, `carry_kind = gather_kind`.
     - When `carry_amount == capacity`, go deliver. If the node runs out first and there's room left, find the next node (it's allowed to deliver a partial load if no node is reachable).
   - **RETURNING:**
     - Choose the nearest complete `command_center` or `storage` building by squared distance, falling back to the next if unreachable. Walk to its ring.
     - On arrival: `state.resources.add(carry_kind, carry_amount)`, emit `state.resource_delivered(carry_kind, carry_amount, b.center_world())`, set carry to 0 and `carry_kind` to "".
     - Then go back to `work_tile` if it still has an amount, otherwise to the nearest node again.
5. `jobs.gd`: `Survivor.Job.GATHERER` → `GathererJob.tick`.
6. `game_state.gd`:
   - `signal resource_delivered(kind: String, amount: int, world_pos: Vector2)`.
   - `set_job(uid: int, job: int, gather_kind: String = "") -> bool`. A non-empty `gather_kind` must be "wood" or "scrap" (anything else → return false, no change), and it sets `s.gather_kind`. If the survivor carries anything when its job or kind changes, add the load to resources immediately (no popup) and clear the carry. Also reset `work_tile`.

## Acceptance criteria

- New game: survivor jobs are Builder, Gatherer (wood), Gatherer (wood), Gatherer (scrap).
- Harvest rate: a wood gatherer teleported into a tree's ring with an empty load holds 2 wood after 3.1 s of `tick(0.1)` and 1 after 2.9 s. With a complete lumber yard whose centre is within 6 tiles of that tree, it holds 3 after 3.1 s. Scrap: 1 after 2.6 s.
- Carry capacity: the load never exceeds `carry_capacity`. A full gatherer walks to a drop-off.
- Delivery: ResourceStore wood rises by exactly the carried amount, and `resource_delivered` fires once with that amount. With a complete Storage much closer than the CC, the delivery goes to the Storage. An incomplete Storage blueprint is ignored.
- Depletion: a node with 3 wood left is harvested to 0, its tile becomes passable, `occupant_at` is NONE, and the gatherer moves on to another node.
- `harvest()` emits `changed` only on depletion.
- 60 sim-seconds of a default new game (seed 1337, `tick(0.1)`): total wood + scrap delivered is > 0 and no survivor ever stands on an impassable tile.
- `set_job(uid, GATHERER, "scrap")` switches kind. A bad kind returns false. Switching job while carrying 6 wood adds 6 wood to resources.
- FloatingTextLayer: `spawn` shows a label with the right text. After `advance(1.3)` it's hidden and back in the pool. 40 spawns never create more than 32 labels.
- `gathering` screenshot: gatherers next to trees or scrap (or walking with loads), the CC in view, and a "+N wood" popup.
- `default`, `buildings_placed`, `survivors`, `construction` still render correctly (gatherers walking away in `default` is expected).
- All tests pass with no `SCRIPT ERROR` line. Smoke passes with no `ERROR:`. Static typing. New files under ~250 lines.

## Pitfalls

- Trees, scrap and rocks are impassable. Gatherers stand in the node's 1-tile ring, never on it. Rocks are not nodes.
- `find_path_adjacent` returning `[]` while already in the ring means "arrived". Check `Grid.in_ring` first.
- Don't scan all 2304 map tiles every tick. Search for nodes only when a gatherer needs a new target.
- Popups are presentation only. The sim emits a signal and never touches nodes.
- Godot commands: only the ones in `project/ARCHITECTURE.md`. Always pass `--path game`.
