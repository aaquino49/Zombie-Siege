# T-111: Settings, How to Play and Credits screens

Milestone: M6 | Type: code | Owner: gemini | Scenario: `settings_screen`

## Goal

GDD §16 / owner request R-5: three new themed screens. **Settings** (master/SFX/music volume, fullscreen or windowed,
default game speed 1×/2×/3×, hints on/off), **How to Play** (goal, controls, tips) and **Credits**. All reachable
from the main menu; Settings also from the pause menu.

## Context

- Menus were restyled in T-110: `game/scenes/ui/main_menu.tscn` + `game/scripts/ui/main_menu.gd`,
  `pause_menu.tscn/.gd`, all using the project Theme (`game/assets/pixel/ui/game_theme.tres`), `MenuStyle.apply()`
  (`game/scripts/ui/menu_style.gd`), `UiFont` sizes (multiples of 11 only, see T-122) and `ScreenFade` (via `Game`).
  Node layout pattern: `Dim/Center/Panel/Margin/Content/{Title, ..., Buttons/...}`, stacked 320×48 buttons.
- Settings storage: `AudioSettings` (`game/scripts/ui/audio_settings.gd`, `PATH = "user://settings.cfg"`, buses
  Master/SFX/Music, `load_volumes/save_volumes/apply`, all take an optional `path`) and `HintSettings`
  (`hint_settings.gd`, same file). The pause menu already has volume sliders and a Hints toggle.
- Speeds: `GameClock.speed` (1..3) with `set_speed`; Space pauses, 1/2/3 change speed (GDD §11).
- Credits source of truth: `CREDITS.md` at the repo root (Kenney, Ittai Manero, audio, Pixelify Sans / Siege Pixel
  OFL, engine). Add "Made by an AI team: Claude, Gemini, ChatGPT" at the end.

## Do

1. **`GameSettings`** (`game/scripts/ui/game_settings.gd`, static, same `settings.cfg`, optional `path` arg):
   `load_window_mode/save_window_mode` ("windowed"/"fullscreen", default windowed) and
   `load_default_speed/save_default_speed` (1..3, default 1, clamp bad values), plus `apply_window_mode()`.
   Existing audio and hint keys must survive a save of the new keys (and vice versa).
2. **Settings screen** (`game/scenes/ui/settings_screen.tscn` + `settings_screen.gd`, a CanvasLayer panel in the
   same style): three volume sliders (move the pause menu's slider logic here, or share one helper; don't duplicate
   the bus code), Fullscreen check button, Default speed option (1× / 2× / 3×), Hints toggle, Back. Changes apply
   immediately and save. Window mode is a no-op in headless runs.
3. **How to Play** (`how_to_play.tscn/.gd`): Goal (survive N nights, build the Radio Tower, get rescued, using
   `balance("nights_to_win")`), Controls (from GDD §11: camera, time, build, select, roster R, pause Esc), and 4–6
   short tips (farms before night 3, walls + gate, ammo from the Workshop, guards in watchtowers, shelters for
   everyone at night). Use a vertical `ScrollContainer` so it always fits 1280×720.
4. **Credits** (`credits_screen.tscn/.gd`): text from `CREDITS.md`, rewritten as short readable lines (names,
   licences), scrollable.
5. **Main menu:** buttons New Game, How to Play, Settings, Credits, Quit. **Pause menu:** replace the inline
   volume/hints block with a Settings button (Resume, Restart, Settings, Quit to Menu). Back button and Esc close a
   screen and return to where it was opened from; Esc must not also close/open the pause menu in the same press.
6. **Default speed:** `Game.start_new_game()` (or wherever the clock is first set up) applies the saved default
   speed; the game still starts paused/locked the same way it does now if it does.
7. Scenarios `settings_screen`, `how_to_play`, `credits_screen` (open the screen over the main menu) and update
   `pause_menu` scenario. Update `qa_m4_menu_flow.gd` / `qa_t025_menu_flow.gd` for the new buttons.
8. Update GDD §11 "Screens" line in `work.json` notes (the quarterback updates the GDD) and README controls if needed.

## Acceptance criteria

- `settings_screen`, `how_to_play`, `credits_screen` and `main_menu` captures (1280×720, 1×) are readable, on-theme,
  with crisp `UiFont` sizes and nothing clipped.
- Round-trip test on a temp path: saving window mode and default speed keeps existing audio and hint keys, and saving
  volumes keeps the new keys; bad values clamp to defaults.
- A new game starts at the saved default speed (test).
- From the pause menu: Settings → Back returns to the pause menu; Esc from Settings returns there too and does not
  unpause the game in the same press (test or menu-flow scenario).
- All tests pass; import, smoke and screenshot clean.

## Pitfalls

- Don't touch the title background (T-112 replaces it later) or the Dawn Report (T-135).
- `DisplayServer.window_set_mode` in headless: guard with `DisplayServer.get_name() == "headless"`.
- Settings opened from the pause menu runs while the tree is paused: set `process_mode = ALWAYS` like the pause menu.
- Only `UiFont` sizes; the T-122 test rejects any other font size.
