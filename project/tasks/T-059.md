# T-059: Gathering polish: scenario framing + GathererJob cleanup

Milestone: M2 | Type: code | Owner: gemini | Scenario: `gathering`
Depends on: T-013. A follow-up from the T-013 review. No gameplay-rule changes.

## Goal and files

1. **Scenario framing** (`game/dev/scenarios/gathering.gd`). `Survivor.pos` is already in world pixels, but the camera block averages `s.pos * float(Grid.TILE)`, so the camera gets clamped to the map edge, and zoom 0.35 makes the "+10 wood" popup about 6 px tall.
   - Average `s.pos` directly and centre the camera between `cc.center_world()` and that average.
   - Choose the largest zoom (in 0.6–1.0) that still keeps the CC and every wood gatherer inside the 1280×720 view, with a 64 px margin.
   - Update `test_gathering_acceptance_qa.gd::test_gathering_scenario_keeps_harvesting_gatherers_in_view` to match.
2. **GathererJob deliver** (`game/scripts/sim/gatherer_job.gd`):
   - `_do_deliver` should credit the building whose ring the survivor is actually standing in. The RETURNING arrival check and `_go_deliver` already find it, so pass it as a parameter (`_do_deliver(state, s, b)`) instead of re-picking the nearest origin.
   - Remove the `s.pos * float(Grid.TILE)` fallback: use `b.center_world()`, or `s.pos` if `b` is null.
   - Type `state: GameState` on GathererJob's static functions.
3. `game/scripts/world/floating_text_layer.gd`: type `var oldest: Dictionary` (and any other untyped locals).
4. `game/scripts/sim/game_state.gd` `set_job`: bank the carried load only when the job or the gather kind actually changes. Calling `set_job` with the same job and kind must leave the carry, path and work state alone.

## Acceptance criteria

- `gathering` screenshot: the CC, the wood gatherers at their trees and a legible "+10 wood" popup (text readable at 1280×720) are all in view, and the camera position isn't clamped to the map edge.
- `GathererJob._do_deliver` credits the building whose ring the survivor stands in (test: a complete Storage and the CC, survivor in the Storage ring → `resource_delivered` world_pos == storage centre). The fallback position uses `s.pos` without multiplying by `Grid.TILE`.
- Test: `set_job` with the same job and kind keeps `carry_amount` unchanged; changing either one banks the load.
- default, survivors, buildings_placed and construction screenshots are unchanged.
- All tests pass with no SCRIPT ERROR. Smoke passes.

## Pitfalls

- If T-014/T-061/T-056 have already landed, the gathering scenario's tick loop must stay inside day 1, so nobody goes hungry or shelters.
- Godot commands: only the ones in `project/ARCHITECTURE.md`. Always pass `--path game`. Scratch output goes under `project/runs/` or `game/*_out.txt`, never the repo root.
