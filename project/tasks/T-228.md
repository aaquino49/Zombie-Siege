# T-228: Polish: align roster status column when a job dropdown shows Research

Milestone: M12 | Type: code | Owner: gemini | Scenario: `ui_roster` | skip_qa
Depends on: T-226 (done). T-221 (final QA) now waits for this task.

## Goal

In T-226's captures (`project/runs/T-226/a1/full_roster_top.png`,
`full_roster_bottom.png`, rows Heidi/Sybil/Noah) rows whose job dropdown
shows "Research" are about 4 px wider in the job column, so their status
text starts further right and the column looks ragged. Every row's job
button must be the same width.

## Context

`RosterPanel._rebuild_rows` in `game/scripts/ui/roster_panel.gd` (~line 115)
sets `job_btn.custom_minimum_size.x = _button_text_width(...)` plus the arrow
icon width. OptionButton also reserves its `arrow_margin` theme constant
(and `h_separation` between text and arrow), so the widest label overflows
the minimum and that row's button grows. Add those theme constants (read
from the button with `get_theme_constant`, not hard-coded) to the minimum,
so the minimum always covers the widest label. Alternatively set
`clip_text`/a fixed width, as long as no label is clipped.

## Files (fence)

Only `game/scripts/ui/roster_panel.gd` and `game/tests/test_roster_layout.gd`.

## Acceptance criteria

- With a full roster at 1280x720, every row's job OptionButton has the same
  rendered `size.x` whatever its label (test covers rows showing "Idle" and
  "Research").
- The status label starts at the same x in every roster row (test).
- No job label is clipped; existing roster tests pass; import, full suite
  and 300-frame smoke clean; `ui_roster` capture inspected at 1x.

## Pitfalls

Keep UiFont sizes (multiples of 11) and LF endings. Don't touch the name,
mood or day-off columns. The panel must still fit 1280x720.
