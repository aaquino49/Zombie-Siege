# T-187: New Game seed reroll + seed shown in the pause menu

Milestone: M9 | Type: code | Owner: gemini | Scenario: `main_menu` | skip QA (covered by T-190)

GDD §19.2. New Game rolls a hidden seed and Restart keeps it, but the
player can never see it or try another map without starting. Show the
seed and let them reroll before committing.

## Scope fence

Touch `game/scripts/autoload/game.gd` (seed handling), the difficulty
picker (`game/scripts/ui/difficulty_picker.gd` + scene), `game/scripts/ui/pause_menu.gd`
(+ scene label), `game/tests/test_seed_reroll.gd` (new) and
`project/assumptions.md`. No sim, save or balance changes. Keep every
existing public method name so `qa_t025_menu_flow` keeps passing.

## Do

1. `Game` gets `preview_seed: int` plus `reroll_seed()` (add-only; existing
   `next_seed`/`start_new_game`/`restart` behaviour unchanged). Opening New
   Game sets `preview_seed = next_seed`; starting uses `preview_seed`.
2. Difficulty picker shows "Seed: 12345" with a "Reroll" button next to the
   difficulty buttons. Reroll picks a new random seed and updates the label
   only. Starting a game uses the preview seed (map identical to a direct
   `new_game(preview_seed)` in tests).
3. Pause menu shows "Seed 12345 · Normal" (seed + difficulty) in small text
   under the buttons. Read-only.
4. Tests: reroll changes the seed; two starts with the same preview seed
   generate identical maps; restart still keeps the run seed; pause label
   shows both values.
5. `main_menu` capture shows the picker with seed + Reroll readable at
   1280x720.

## Acceptance criteria

- Reroll visibly changes the seed; starting twice on one preview seed
  gives the same map; Restart keeps the run seed.
- Pause menu seed/difficulty line readable, no overlap at 1280x720.
- `qa_t025_menu_flow` and all other tests pass; import/smoke clean.

## Pitfalls

- The menu RNG must not consume the game RNG stream (use a separate
  `RandomNumberGenerator` or `randi()`); determinism tests depend on it.
- Reroll must not start, reload or unpause anything.
- Keep LF line endings.
