# T-066: Fix: a survivor covered by a building while standing still stays on solid ground and never shelters

Milestone: M2 | Type: code | Owner: gemini | Scenario: `qa_m2_blocked_worker`
Depends on: T-016 (M2 QA, which found the bug). Absorbs QA duplicate T-064.

## Goal

A major bug from M2 QA (see `project/runs/T-016/a1/bugs.json` and `qa_m2_blocked_worker.png`). Use seed 1337 with a complete farm at CC origin + (0,-3). Frank starts on tile (23,22) and is set to Farmer. Tick once, then call `GameState.try_place("wooden_wall", Frank's tile)`. It returns OK, and a Builder completes the wall. Frank stays on the now-impassable tile (23,22). At night he stands outside, Idle, with `sheltered == false`, even though the CC has free beds.

After this task, nobody can ever end up standing on an impassable tile, and a survivor who was covered by a building shelters normally.

## Root causes

1. T-055 only fixed `Pathfinder.find_path` when the path starts on a solid tile. `SurvivorStore.tick` skips survivors that aren't moving, so a stationary worker (farming, crafting, harvesting) is never relocated.
2. `Pathfinder.find_path_adjacent` (`game/scripts/sim/pathfinder.gd`) returns `[]` when `from` is already in the target ring, even if `from` is solid. ShelterRules and the jobs read that as "arrived" and then fail the passable-approach check, so the survivor gets stuck.
3. Production jobs keep using a work-ring tile that is now blocked.

## Fix

1. **Evict covered survivors (`game/scripts/sim/survivor_store.gd` or `game_state.gd`).** Add `func evict_from_solid(map: WorldMap) -> void`. For every survivor that isn't sheltered and whose tile is not passable (a gate counts as passable, as in `SurvivorStore.tick`), BFS outward (4-neighbour, deterministic order: up, left, right, down, or sorted y then x per ring) to the nearest passable tile. Snap `pos` to that tile's centre, clear `path`, set `work_tile = Vector2i(-1, -1)`, `activity = IDLE`, `job_timer = 0`. Keep `job`, `gather_kind`, `work_uid` and the carried load. The job logic picks a valid tile on the next tick.
   - Call it from `GameState.tick` once per step, **before** `Jobs.tick`. It is O(survivors) and does a BFS only for survivors that are actually covered, so it is cheap.
2. **`find_path_adjacent`:** return the early `[]` only when `from` is in the ring **and** passable (or a gate). If `from` is solid, search normally (`find_path` already handles a solid start).
3. Don't change placement rules. Placing on a survivor stays legal.

## Files

- `game/scripts/sim/survivor_store.gd` (or `game_state.gd`): `evict_from_solid`.
- `game/scripts/sim/game_state.gd`: call it at the start of each `tick` step.
- `game/scripts/sim/pathfinder.gd`: the `find_path_adjacent` guard.
- `game/tests/test_colony_sim_qa.gd`: turn on the known-bug assertions in `test_blueprint_over_stationary_farmer_recovers_and_shelters` (set `check_known_bug` to true, or remove the guard and the `# BUG T-016` comment).
- `game/tests/test_pathfinder.gd` and a survivor test file (for example `test_survivors.gd` or the existing T-055 test file): the new unit tests below.

## Tests

- `test_blueprint_over_stationary_farmer_recovers_and_shelters` passes with the bug assertions on: Frank ends on a passable tile and is sheltered before dawn.
- `Pathfinder.find_path_adjacent` from a solid tile inside the target ring returns a non-empty path to a passable ring tile.
- A stationary survivor (empty path, activity FARMING) on a tile that becomes impassable (`map.occupy`) is on a passable tile after one `state.tick(0.1)`, with its job unchanged.
- A survivor already on a passable tile is not moved by `evict_from_solid` (position unchanged).
- A sheltered survivor is never evicted (sheltered survivors are inside a building by design).
- The same seed and inputs give the same final tile (determinism).

## Pitfalls

- A gate is passable for survivors. Don't evict someone standing on a gate.
- Don't move survivors who are already walking through `SurvivorStore.tick`'s solid-next-tile repath unless their **current** tile is solid.
- Existing tests that place buildings next to survivors must still pass. If one fails, find out why before changing the test.
- Static typing everywhere. Files under ~400 lines. Use only the Godot commands in `project/ARCHITECTURE.md`, always with `--path game`. Scratch output goes under `project/runs/` or `game/*_out.txt`.
