# Asset index

## T-031 title background and app icon

Release art is composed deterministically from the existing Kenney-derived game sprites by `project/tools/compose_title.py`; no generated-image service or additional art source is used. The title is an opaque 1280x720 overhead camp at dusk, with the central 640x330 area (320,195)-(960,525) reserved for the menu. Buildings, construction, survivors and approaching zombies frame that area. Native tile texture is reduced in contrast, the scene receives a uniform dusk tint and flat edge shade bands, and the retained 2x composition is Lanczos-downscaled. The icon combines the alpha-trimmed Command Center with overhead radio hardware on a transparent 4x canvas, then Lanczos-downscales; its silhouette remains readable at 32px.

## T-083 rescue helicopter

Separate transparent, east-facing overhead sprites, prepared with `project/tools/prepare_helicopter.py` using pivot-centred trimming and Lanczos downscaling. Body canvas: 176x96, hub (88,48); rotor canvas: 192x192, hub (96,96). The body contains no main blades or drop shadow. Rotor alpha is multiplied by 0.65 while retaining the generated trailing blur; no directional shadow is baked in. Source manifests are in `asset_library/generated/originals/t054_sources.json`; native and half-size comparisons are in `project/runs/T-054/a1/contact_sheet.png`.
